# 제로가드닝 통합관리

정원식물 온오프라인 판매업체의 입고/주문/명세서/거래처/고객 통합관리 프로그램.

## 사용

배포된 URL을 브라우저로 열기 (Chrome / Edge 권장).

## 개발

`index.html` 한 파일로 동작. 수정 후 GitHub에 푸시하면 1~2분 내 자동 배포됨.

## 데이터

현재 단계: 브라우저 localStorage (사용자별 분리)
다음 단계: 클라우드 DB (Supabase) — 모든 사용자 공유

## 백업

상단 "📤 백업 내보내기" 버튼으로 수시로 JSON 파일을 받아 보관할 것.
