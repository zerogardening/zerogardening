### 방어가 3겹으로 들어갔다 — 셋 다 실제로 돌려 확인했다

1. **`13b` `폴더옵션()` (27줄)** — `고르개.value = 자().실제폴더(지금)`.
   없는 이름이면 `''` 가 들어가 select 가 언제나 미분류에 붙는다. `selectedIndex=-1` 이 안 나온다
   `그리기()` 323줄에서 `상태.담을폴더` 자체를 `실제폴더()` 로 되맞춘다 — 탭에서 돌아올 때마다 리셋
2. **`13a` `담기()`·`옮기기()` (37·69줄)** — 마지막 그물. 콘솔에서 직접 불러 확인했다
   ```
   ZG.소싱자료.담기('수국','봄정원',{})  → 저장된 분류 ''   (봄정원 폴더는 없다)
   ZG.소싱자료.옮기기('수국','없는폴더') → 저장된 분류 ''
   ```
3. **`13d` `옮기개()` (85줄)** — 줄의 「폴더 옮기기」 select 도 `실제폴더()` 로 맞춘다
