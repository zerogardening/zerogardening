## 2. 🔴 이게 없으면 v3로 못 넘어간다 — 4건

### 🔴① 카페24 주문 파일을 올릴 수가 없다
- **무슨 기능** — 카페24에서 받은 주문 엑셀/CSV를 끌어다 놓으면 그날 주문이 통째로 들어오고, 하루 여러 번 올리면 회차 폴더(`260506-01`)가 자동으로 생기던 것.
- **없으면 못 하시는 일** — **그날 주문 전체가 v3에 안 들어온다.** 손으로 한 건씩 치는 수밖에 없다. 주문이 없으니 출고리스트·동봉카드·송장도 줄줄이 못 쓴다.
- 지금 v3 상태 — 주문 화면의 파일 버튼을 누르면 「실제 엑셀 양식을 받은 뒤 연결합니다」라는 안내만 뜬다.
- 구 프로그램 위치 — `app.html` 2847행(주문 파일 업로드 칸)·3027행(카페24 주문 CSV 업로드)·9057행부터(업로드 처리)

### 🔴② 카페24 주문 → 로젠 대량등록 파일 만들기
- **무슨 기능** — 그날 주문을 로젠택배에 한꺼번에 올릴 엑셀로 바꿔주던 것. 합포장은 상품명 뒤에 `/`를 붙여 로젠이 한 상자로 알아보게 하고, 유통명 치환·박스 운임·작업자 포장순서 정렬까지 들어 있었다.
- **없으면 못 하시는 일** — **택배 접수를 못 한다.** 송장이 안 나오니 그 뒤 배송완료 처리도 시작을 못 한다.
- 지금 v3 상태 — 버튼은 있으나 ①과 같은 안내만 뜬다. (규칙은 `v3/설계/엑셀변환-규칙.md`에 이미 정리돼 있어 만들 준비는 돼 있다)
- 구 프로그램 위치 — `app.html` 9610~9975행

### 🔴③ 데이터가 이 브라우저 한 대에만 남는다
- **무슨 기능** — 구 프로그램은 저장할 때마다 인터넷 서버(Supabase)에 같이 올려서, PC에서 넣은 것이 아이폰에서도 보이고 그 반대도 됐다.
- **없으면 못 하시는 일** — **밭에서 폰으로 넣은 입고가 사무실 PC에 안 보인다.** 반대도 마찬가지. 브라우저 기록을 지우거나 기기가 고장 나면 **그때까지 넣은 것이 통째로 사라진다.**
- 지금 v3 상태 — 서버로 보내는 코드가 v3 전체에 한 줄도 없다(브라우저 저장만). 구 프로그램의 「나중 저장이 앞 저장을 덮는」 문제를 고치려고 표를 나눠 둔 데까지는 됐지만, **서버에 붙는 일은 아직 안 했다.**
- 구 프로그램 위치 — `app.html` 4384행

### 🔴④ 백업 내보내기가 없다
- **무슨 기능** — 「📤 백업 내보내기」로 전체 데이터를 파일 하나로 받아 두고, 「📥 불러오기」로 되돌리던 것.
- **없으면 못 하시는 일** — **사고가 나도 되돌릴 방법이 없다.** ③과 겹쳐서 위험이 두 배가 된다.
- 지금 v3 상태 — 구 프로그램 백업을 v3로 **들여오는** 도구(`이사.html`)만 있고, v3에서 **내보내는** 길은 없다.
- 구 프로그램 위치 — `app.html` 2230~2231행
