## 🔴 지운 폴더로 즐겨찾기가 담겨 상품분류 어디에도 안 나온다

**등급 근거** — 우람님이 ★을 눌러 담은 줄이 「상품분류」 탭 왼쪽 목록·미분류·어느 폴더에도 안 뜬다.
저장소에는 남아 있지만 화면에서는 **담은 것이 사라진 것으로 보인다.**

### 눌러서 그대로 재현된다 (PC 1440px · 실이사데이터)

1. 「키워드 검색」 탭 → **담을 폴더** → `＋ 새 폴더…` → 「봄정원」 만들기
2. 「상품분류」 탭 → 봄정원 → **폴더 삭제** (확인)
3. 「키워드 검색」 탭으로 돌아온다 → **담을 폴더 칸이 빈칸이다** (`selectedIndex = -1`)
   → 샷 `19-🔴-담을폴더칸이-빈칸.png`
4. 「수국」 검색 → ★ 클릭 → 토스트가 **`⭐ 즐겨찾기 → 봄정원: 수국`** 이라고 뜬다 (지운 폴더 이름이다)
   → 샷 `19b-🔴-없는폴더로-담김-토스트.png`
5. 「상품분류」 탭 → 왼쪽은 `🗂 미분류 15` 하나뿐, 미분류 표에 수국이 **없다**. 즐겨찾기 총수만 15→16으로 늘었다
   → 샷 `19c-🔴-상품분류-어디에도-없음.png`

```
저장된 레코드: { 키워드:"수국", 분류:"봄정원" }   ← 「봄정원」 폴더는 이미 없다
zg.v3.분류폴더: []
```

그 줄의 「담긴 폴더」 select 도 `selectedIndex = -1` 빈칸으로 뜬다(샷 19b 오른쪽 끝).
되살리는 길은 그 키워드를 다시 검색해 빈칸 select 를 「🗂 미분류」로 고르는 것뿐인데,
우람님이 그 키워드를 기억하고 있어야만 가능하다.

### 원인

`js/13b-키워드검색.js`
- `상태.담을폴더`(10줄)가 **모듈 수명 내내 살아 있다.** 폴더가 지워져도 옛 이름을 그대로 들고 있다
- `폴더옵션()`(20~27줄) `고르개.value = 지금 || ''` — 없는 값이면 select 가 조용히 빈칸이 된다. 되돌리지 않는다
- `별토글()`(60줄) `var 폴더 = u.폰인가() ? '' : 상태.담을폴더;` — 검증 없이 그대로 담는다

`js/13a-소싱자료.js`
- `담기()`·`옮기기()`가 폴더 이름이 실재하는지 보지 않는다
- `폴더별개수()`(133~142줄)는 고아 분류를 세어 주지만 `13d.왼쪽()`·`타일들()`은 `폴더들()`만 돌아서 **그 숫자가 화면에 영영 안 나온다** — 안전망이 반쪽이다

### 고칠 곳 (3군데 중 최소 2군데)

1. `js/13b-키워드검색.js` `폴더옵션()` — `고르개.value` 를 넣은 뒤 `if (고르개.selectedIndex < 0) 고르개.value = '';`
   `담을폴더칸()`에서는 그 결과로 `상태.담을폴더` 를 되맞춘다
2. `js/13a-소싱자료.js` `담기()`·`옮기기()` — 마지막 그물. `폴더찾기(폴더)` 가 없으면 `''`(미분류)로 저장한다
3. (권장) `js/13d-상품분류.js` `왼쪽()`·`타일들()` — `폴더별개수()` 가 이미 잡아 놓은 고아 분류를 목록에 함께 띄우거나, 부팅 때 한 번 `''` 로 정리한다

폰은 `별토글()`이 언제나 `''` 를 쓰므로 **PC 전용 버그다.**
