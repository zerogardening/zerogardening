## 🔴 반려 사유 (dev-builder)

### 1. 27cm 품목을 고르면 소리 없이 15cm 코드가 만들어진다

`js/08c-주문입력.js:222~225`

```js
var 최근 = Number(String(g.최근규격 || '').replace(/[^0-9]/g, '')) || 0;
if (사이즈들.indexOf(최근) >= 0) { st.cm = 최근; ... }   // 27 이면 아무것도 안 한다
```

드롭다운이 10·15·18·21뿐이라 등록 규격이 27cm이면 `st.cm`이 기본값 15에 그대로 남는다.

| 재현 (폰) | 결과 | 옳은 값 |
|---|---|---|
| ＋수동주문 → 품목명 `억새` → 후보 첫 줄 클릭 | 코드줄 `MIS01-15 · 재고 0`, 저장 시 단가 0원 | `MIS01-27` · 4,800 |
| 품목명 `자엽안개` → 후보 첫 줄 클릭 | `COR01-15` · 0원 | `COR01-27` · 16,500 |

없는 SKU가 주문에 들어가 재고 차감·출고리스트가 엉뚱한 코드로 간다.
기능명세 §품목코드 생성 「SKU 단위 = 품목명 + 규격」 위반.
업무규칙 §2 기본 선택지도 **10 / 15 / 18 / 21 / 27cm** 다 — 27이 빠졌다.

### 2. 수동주문 단가에 매입단가가 들어간다
