## 3. 🔴-1 — html 4개에 `<<script`. 스크립트 한 개씩 통째로 안 실린다

`index.html`·`주문.html`·`업체.html`·`소싱.html`의 **26행**이 전부 이렇다.

```html
<<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
script src="js/lib/xlsx.min.js"></script>      ← 앞의 '<' 를 CDN 줄이 먹었다
```

CDN 줄을 끼워 넣을 때 **바로 아래 줄의 여는 `<` 를 가져가 버렸다.**
HTML 파서는 `<<` 를 「`<` 라는 글자 + 새 태그」로 읽으므로, **다음 줄은 태그가 아니라 그냥 글자**가 된다.

**실제 브라우저(Chrome)로 확인했다.** 같은 모양의 최소 시험 페이지를 만들어 서버 접근 로그를 봤다.

```
GET /parse시험/a.html
GET /parse시험/두번째.js?t=1      ← 첫번째.js 는 요청조차 없다
```

| 파일 | 사라진 스크립트 | 그래서 |
|---|---|---|
| `주문.html` | **`js/lib/xlsx.min.js`** | 🔴 **`XLSX is not defined`.** 주문 엑셀 올리기·송장 파일 내보내기·배송완료 변환이 **전부 죽는다.** 우람님이 매일 쓰시는 기능이다 |
| `index.html` | `js/00-시드.js` | `ZG.시드`가 없다 → 새 기기·`?reset=1`·로그아웃 상태에서 `부팅()`이 `ZG.시드.심기()`에서 TypeError |
| `업체.html` | `js/00-시드.js` | 위와 같다 |
| `소싱.html` | `js/00-시드.js` | 위와 같다 |

덤으로 **`<body>` 맨 앞에 `<` 글자 하나가 그대로 찍힌다**(네 화면 전부).

이전 커밋 `94d3055`에는 네 파일 모두 `<script src="js/00-시드.js?v=12"></script>`(주문은 `xlsx.min.js`)가 멀쩡히 있었다. **이번 커밋이 낸 회귀다.**
`이사.html`(64행)만 정상이다.

**고칠 것** — 네 파일 26~27행. `<<script` 의 `<` 하나를 지우고 다음 줄 맨 앞에 `<` 를 되돌린다.

## 4. 🔴-2 — 캐시가 다른 탭 갱신을 못 본다. 탭 두 개면 입력이 사라진다

`01-저장소.js`의 캐시(35행 `var 캐시 = {}`)를 **무효화하는 곳이 어디에도 없다.**
`저장()`·`전부지우기()`가 자기 탭 캐시를 갱신할 뿐, 다른 탭이 localStorage를 바꿔도 이 탭은 옛 사본을 계속 돌려준다.

그런데 **`storage` 이벤트를 듣는 화면이 이미 4개 있다** — `07-앱.js:154`·`08b-주문목록.js:654`·`12-업체앱.js:156`·`14-소싱앱.js:149`.
넷 다 `다시그리기()`를 부르는데, 그 `다시그리기`가 `읽기()`로 **낡은 캐시**를 읽으므로 **화면이 안 바뀐다.** 있던 기능이 죽었다.

더 나쁜 것은 그다음이다. jsc로 재현했다.

```
탭 B가 한 번 읽는다 (캐시 채워짐)
탭 A가 입고 1건을 넣는다 → localStorage = [i1, i2, 탭A가 넣은 입고]
탭 B에서 입고를 하나 더 넣는다 (덧붙이기 → 낡은 캐시를 읽어 덮어쓴다)

localStorage 최종: ["i1","i2","탭B가 넣은 입고"]
FAIL 탭 A 입고가 사라졌다 — 데이터 유실
```

`01-저장소.js` 머리 주석이 **「다른 탭이 그 사이에 넣은 것을 지우지 않기 위해서다」**라고 약속한 바로 그 보장이 캐시 때문에 깨졌다.
설계 §4-1의 「동작은 100% 같다」도 이 대목에서 사실이 아니다.

- 로그인 + 온라인이면 Realtime이 몇 초 뒤 메워 준다(에코 맵은 탭마다 따로라 되돌아온 줄을 안 버린다)
- **밭에서 끊겼거나 CDN이 안 열리면 그대로 영구 유실이다.** 우람님은 상품 탭과 주문 탭을 같이 띄워 두신다

**고칠 것** — `01-저장소.js`에 한 줄이면 된다.

```js
window.addEventListener('storage', function (e) { if (e.key) delete 캐시[e.key]; });
```

(`전부지우기()`의 `캐시 = {}`는 그대로 둬도 된다.)
