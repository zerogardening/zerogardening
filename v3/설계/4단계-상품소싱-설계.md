# v3 4단계 설계 — 상품소싱 (키워드 검색 · 상품분류)

시안 `v3/시안/04-상품소싱-macA.html`(+png) 기준. **컨펌 대기 중이나 우람님 외출 예외 규칙으로 그대로 진행한다.**
기존 구현은 `app.html` 3104~3180(HTML) · 15582~16400(JS)에서 배워 옮긴다. **다시 설계하지 않는다.**

애니메이션 · 접근성 · CSS 변수 · 저장소 규약 · IME 안전입력은 **「1단계 설계 §3-7 · §10 · §11」, 「3단계 설계 §6」 그대로.** 여기 다시 적지 않는다.
페이지 셸(사이드바 라우팅 · 탭 전환 · 저장소 부팅 · 폰/PC 전환)은 **`js/12-업체앱.js`와 같다.** 아래 §5에 **다른 것만** 적는다.

이번에 만드는 것은 **두 가지뿐이다** — 키워드 검색 · 상품분류(폴더). 추천 점수 · 랭킹 · 수익성 · AI 픽 · 쿠팡 리포트 · 경쟁사 가격은 **넣지 않는다**(§9).

## 2. 저장 구조 — 이미 있는 키를 쓴다. 새 키를 만들지 않는다

세 키 모두 `js/01-저장소.js`에 이미 있고 실데이터가 들어가 있다(즐겨찾기 15 · 키워드 66 · 분류폴더 0).

### 2-1. 즐겨찾기 (`zg.v3.즐겨찾기`) — 표. 한 줄 = 키워드 하나

| 필드 | 타입 | 값 예 | 이사 원본(`99-이사.js` 391행) | 설명 |
|---|---|---|---|---|
| `키워드` | string | `"핑크뮬리"` | `f.name` | 🔴 **PK다. 같은 키워드는 한 줄뿐** |
| `분류` | string | `""` | `f.folder ?? ''` | 🔴 **폴더 id가 아니라 폴더 이름이다.** `''` = 미분류 |
| `유형` | string | `"관목"` | `f.type` | 화면에 안 쓴다. **지우지 말고 보존만** |
| `시즌` | string | `"SPR"` | `f.season` | 위와 같다 |
| `월검색` `연검색` `PC` `모바일` | number | `5600` `538248` `680` `4920` | | 담을 때의 검색량 스냅샷 |
| `상품수` `판매처수` | number | `6665` `166` | | 위와 같다 |
| `월별추이` | array | `[{period,ratio,est}×12]` | | 이번 화면은 안 그린다. 보존만 |
| `담은때` | number(ms) | `1781874010654` | `f.addedAt` | 시안 「담은 날」은 이 값을 `YYYY-MM-DD`로 |

🔴 **`id` 필드가 없다.** 실데이터 15건에 없고 기존 구현도 이름으로 찾았다(`app.html` `favGet`·`saveFav`). 그러니 `저장소.바꾸기/지우기`(`r.id || r.품목코드`로 찾는다)를 **쓰지 못한다.**
→ `13a`는 **「읽기 → 배열에서 한 건만 손대기 → `전체쓰기`」**로 쓴다. 저장소 규약(1단계 §3-7)과 같은 모양이고, id를 새로 만들지 않는다.

**실데이터에서 확인한 것**
- 15건 전부 `folder`가 없다 → 전부 미분류로 들어와 있다. 폴더 화면은 **빈 폴더 목록 + 미분류 15건**으로 처음 뜬다. 이 상태에서 화면이 비어 보이지 않아야 한다(빈 안내글 필수).
- `유형`이 15건 모두 `"관목"`, `시즌`이 모두 `"SPR"`이다 — 구 화면에서 기본값이 그대로 저장된 것이라 **믿을 수 없는 값이다.** 화면에 쓰지 않기로 한 이유가 이것이다.
- `월검색`·`상품수` 등 숫자는 **실제로 들어 있다**(예: 핑크뮬리 5,600 / 6,665). 받은 때는 2026-06-19다.

### 2-2. 분류폴더 (`zg.v3.분류폴더`) — 표. 실데이터 0건

이사 도구는 구 `favFolders`(**문자열 배열**)를 그대로 옮긴다. 그런데 시안이 「2026-08-05 만듦」을 표시한다 → 문자열로는 못 담는다.

**결정 — 객체 배열로 올린다. 문자열도 읽어준다(하위호환).**

| 필드 | 타입 | 예 |
|---|---|---|
| `이름` | string | `"그늘 식물"` | 🔴 **PK.** 즐겨찾기 `분류`가 이 이름을 가리킨다 |
| `만든때` | number(ms) | `1786000000000` |

`13a.폴더들()`이 읽을 때 `typeof x === 'string' ? {이름:x, 만든때:0} : x`로 흡수한다. 쓸 때는 언제나 객체.
🔴 **`99-이사.js`는 안 고친다** — 실데이터가 0건이고, 설령 문자열이 들어와도 위 어댑터가 흡수한다.

**「미분류」는 저장하지 않는다.** 폴더 목록에 늘 마지막으로 붙는 가상 칸이고, 지울 수 없다(`분류 === ''`인 즐겨찾기 모음).

### 2-3. 키워드 (`zg.v3.키워드`) — 객체 하나. 검색량 캐시

🔴 **신·구 키 규약이 다르다.**
- 구(이사된 66건): 키가 **식물ID**다 — `s_angae` `u_mqkvh6bw`. 62건은 `app.html`에 하드코딩된 SEED 식물표의 id다.
- 신(이번): 키가 **키워드 문자열**이다 — `"수국"`.

식물 후보 목록(plantMaster·SEED)은 v3로 안 옮기므로 id→이름 사전이 없다. 그래서 **이사된 66건은 새 화면 조회에 안 걸린다. 지우지도 않는다**(무해하고, 나중에 쓸 수 있다).
값 모양 — `{ 월검색, PC, 모바일, 상품수, 경쟁, 판매처수, 연검색, 월별추이, 받은때 }`. **이 키를 읽고 쓰는 파일은 `13c` 하나다.**

## 3. 화면별 동작 규칙

### 3-1. 키워드 검색 탭

- 검색칸 1개 + 「담을 폴더」 드롭다운 + 「검색」 버튼. Enter로도 검색한다.
- 🔴 **검색칸은 `u.조합안전입력`을 쓴다** — 안 쓰면 「휴케라」가 `ㅎㅠㅋㅔㄹㅏ`로 깨진다(8/4 사고).
- 결과 표(PC) — `★ / 키워드 / 월간검색수 PC / 월간검색수 모바일 / 상품수 / 담긴 폴더`. **25줄씩 끊고** 시안 `.pager`를 쓴다.
- 값이 없으면 `—` + 머리에 「숫자 칸 비어 있음」 칩. 값이 있으면 그 자리에 숫자를 넣는다(§4-3).
- **★ 한 번이 전부다. 창도 확인도 없다** (기존 `toggleFav` 그대로).
  - `☆ → ★` : 즐겨찾기에 넣는다. 폴더는 위 「담을 폴더」 값. 토스트 `⭐ 즐겨찾기 → 그늘 식물: 수국 묘목`
  - `★ → ☆` : 즐겨찾기에서 **줄째로 지운다**. 토스트 `별표 해제: 수국 묘목`
- 담긴 줄의 「담긴 폴더」 칸은 그 자리 `<select>`로 옮긴다(기존 `_srcMoveFav`). 안 담긴 줄은 「★을 누르면 담깁니다」 글씨.
- 「담을 폴더」 옵션 = `미분류` + 폴더들 + `＋ 새 폴더…`. `＋ 새 폴더…`를 고르면 `물음()`이 뜨고, 만들면 그 폴더가 선택된다(기존 동작). 🔴 **`window.prompt`를 쓰지 않는다.**
- **폰**(시안 ①) — 표 대신 `.kwlist` 카드 줄. 담을 폴더 칸은 **두지 않는다**(시안 그대로). 대신 **담긴 카드를 탭하면 폴더 고르는 시트**가 뜬다. 카드에 `📁 그늘 식물` 뱃지(`.fd`)가 붙는 것이 시안에 이미 있다.

### 3-2. 상품분류 탭

- **PC**(시안 `.fsplit`) — 왼쪽 폴더 목록 + 오른쪽 그 폴더의 표.
  - 왼쪽: 폴더마다 `📁 이름 + 개수`. 구분선 뒤 `🗂 미분류`(항상 있다·못 지운다), 그 아래 `＋ 새 폴더 만들기`.
  - 오른쪽 머리: `📁 이름 · N개 · YYYY-MM-DD 만듦` + `[이름 바꾸기] [폴더 삭제]`. **미분류를 골랐을 때는 두 버튼을 감춘다.**
  - 표: `★ / 키워드 / 담은 날 / 월간검색수 / 폴더 옮기기(select)`
  - `★` 클릭 = **즐겨찾기에서 줄째로 뺀다**(폴더에서만 빼는 게 아니다). 확인창 없다 — 검색 탭 ★과 같은 손놀림이어야 하고 기존 구현도 그렇다. 시안 폰 ③의 「★ 눌러 빼기」와 같다.
- **새 폴더** — `물음()`. 빈 이름·이미 있는 이름이면 막고 `u.흔들기`. 앞뒤 공백은 잘라낸다.
- **폴더 삭제** — `u.확인({위험:true})` → 「폴더 "X"를 지웁니다. 안의 키워드 N개는 **미분류로 갑니다**(지워지지 않습니다)」 → 폴더 제거 + 그 폴더의 즐겨찾기 `분류`를 전부 `''`로.
- **이름 바꾸기**(시안에 새로 생긴 것) — `물음()`. PK가 이름이므로 **폴더 이름과 그 폴더에 든 즐겨찾기의 `분류`를 한 번에 같이 바꾼다.** 하나만 바꾸면 키워드가 없는 폴더를 가리켜 통째로 사라진다. 중복 이름은 막는다.
- **폰** — ② 폴더 타일 격자(2열) → 타일을 탭하면 ③ 폴더 안. `‹ 폴더 목록`으로 돌아온다. 「이름 바꾸기」는 오른쪽 위. 새 폴더는 `＋ 새 폴더` 타일 → 아래에서 올라오는 시트(시안 ④).
- **정렬** — 폴더는 만든 순, 폴더 안 키워드는 **담은때 내림차순**(시안의 담은 날 8/5→7/26 순서와 같다).

## 4. 검색량 — 함수 하나를 한 파일에 몰아둔다 (`js/13c-검색량.js`)

키가 붙는 날 **이 파일 하나만 갈아끼우면 되게** 한다. 다른 파일은 내부를 모른다.

```
ZG.검색량 = {
  키있나()                  // → false  (지금은 언제나)
  안내()                    // → '네이버 검색광고 API 키가 아직 연결되지 않았습니다…' (시안 노란 띠 문구)
  연관(검색어)              // → Promise<{상태, 출처, 목록:[{키워드, 값}]}>
  자세히(키워드들[])         // → Promise<{상태, 값:{ 키워드 → 값객체 }}>
  캐시(키워드)              // → 값객체 | null      (zg.v3.키워드에서 꺼낸다)
  캐시넣기(키워드, 값객체)     // → void
}
```
- `상태` = `'성공'` \| `'키없음'` \| `'실패'` · `출처` = `'네이버'` \| `'내데이터'`
- **값객체** = `{ 월검색, PC, 모바일, 상품수, 경쟁, 판매처수, 연검색, 월별추이, 받은때 }`. **`null`이면 화면은 `—` + 「키 없음」**을 찍는다. 화면은 이 판정만 한다.
- 🔴 **이 파일 밖에서 `fetch`도 `zg.v3.키워드`도 만지지 않는다.**

**4-1. 지금(키 없음)** — `키있나()`는 `false`, `자세히()`는 `{상태:'키없음', 값:{}}`.

**4-2. 🔴 키가 없어도 `연관()`은 목록을 준다 — 내 데이터에서 찾는다**
시안 노란 띠가 「**키워드 목록은 나오지만** 월간검색수·상품수 칸은 비어 있습니다」라고 못박았고, 키 없이도 ★로 담을 수 있어야 화면이 쓸모가 있다. 그래서 `{상태:'키없음', 출처:'내데이터'}`로 이렇게 만든다.

1. **검색어 자체** — 언제나 맨 위(새 키워드를 담는 통로다)
2. 즐겨찾기 `키워드` 중 검색어를 포함하는 것
3. `zg.v3.품목`의 `유통명` 중 검색어를 포함하는 것 (중복 제거)

앞뒤 공백을 자르고 대소문자를 무시한다. 최대 50줄. 하나도 없으면 1번만 나온다. 표 머리는 「내 데이터에서 찾은 N개 — 키가 붙으면 네이버 연관 키워드로 바뀝니다」.

**4-3. 값 채우는 순서** — ① `13c.캐시(키워드)` → ② 없으면 **즐겨찾기 줄에 든 스냅샷**(`월검색·PC·모바일·상품수`) → ③ 그래도 없으면 `null`.
②가 있어 이사된 15건은 **키가 없어도 숫자가 보인다.** 시안이 「—」로 그린 것은 값이 없을 때의 모습이고, 같은 칸의 다른 상태다(시안 「키가 붙는 날 「—」이 숫자로 바뀌는 것이 전부」와 어긋나지 않는다).

**4-4. 키가 들어오는 날 고치는 것** — `13c` 안에서만:
`SUPABASE_URL + '/functions/v1/naver-keyword'`에 `{keywords:[...], trend:true, related:true}`를 POST(헤더 `Authorization: Bearer <anon>` · `apikey`). 응답 `res.results[i].{monthly,pc,mobile,productCount,competition,sellerCount,annual,monthlyTrend,related[{keyword,monthly,comp}]}` · `res.fetchedAt`. **영문→한글 이름 변환도 이 파일 안에서만** 한다. 15개씩 끊어 보내는 것도 기존 그대로(`app.html` `fetchKeywordData`).

## 5. 셸 (`js/14-소싱앱.js`) — 업체앱과 같다. 다른 것만

패턴 원본 = **`js/12-업체앱.js`**. 그대로 베끼고 아래만 바꾼다.

| 자리 | 소싱 |
|---|---|
| 탭 | `검색` · `분류` **두 개.** 서브탭 없다 |
| 상태 | 분류 탭에 `연폴더`(폴더 이름 \| `''`=미분류 \| `null`=폴더 목록) 하나가 더 있다 — **폰에서만** 목록/안을 오간다. PC는 늘 좌우분할 |
| PC 길 | `상품소싱 › 키워드 검색` / `상품소싱 › 상품분류 › 그늘 식물` |
| PC 왼쪽 메뉴 | 상품 · 주문 관리 · 업체 관리 · **🌱 상품소싱(`on`)** — 네 개 |
| 폰 탭줄 | `.toggle`(시안 ①②) — 업체가 쓰는 `.subtabs`가 **아니다** |
| 폰 뒤로 | 폴더 안이면 `‹ 폴더 목록`, 아니면 `‹ 상품`(index.html) |
| 폰 하단탭 | 상품 · 재고 · 주문 · **⋯더보기(`on`)** — 늘리지 않는다 |
| 요약줄 | 검색 탭 `더보기 › 상품소싱` / `즐겨찾기 N` · 분류 탭 `폴더 N개` / `즐겨찾기 N` |

`storage` 이벤트로 다시 그리는 것, `폰질의` change로 다시 그리는 것 모두 12와 같다.

## 6. `css/소싱.css`에 넣을 것

시안 `<style>`에 있고 `공통.css`에 **없는** 것만 옮긴다 — `.nokey` · `.srch` · `.kwlist`/`.kw` · `.folders`/`.ftile` · `.fsplit`/`.flist` · `td .star`/`.sel` · `.ph-card .star`.
`.toggle` · `.pc-tabs` · `.pager` · `.table-card` · `.card` · `.field` · `.btn` · `.chip` · `.hint` · `.ph-*`는 **`공통.css`에 이미 있다. 다시 쓰지 않는다.**
`.phones`/`.phwrap`/`.phcap`/`.phstage`/`.phscrim`/`.noteblk`/`.steps`는 **시안 전시용 껍데기다. 옮기지 않는다.**

`공통.css`에 새로 넣는 것 두 개 — `물음` 대화상자(`.askbox`에 입력칸 한 줄) · `더보기시트`(§7).

## 7. 메뉴 살리기 — 죽은 「소싱 추천」을 「🌱 상품소싱」으로

| 파일 | 자리 | 어떻게 |
|---|---|---|
| `js/07-앱.js` | 12행 `죽은메뉴 = [['🌱','소싱 추천','소싱']]` | 죽은메뉴에서 빼고 **살아있는 링크**로. `location.href='소싱.html'` |
| `js/08b-주문목록.js` | 109~113행 `aria-disabled` 버튼 | 위와 같다 |
| `js/12-업체앱.js` | 37~40행 `aria-disabled` 버튼 | 위와 같다 |

이름은 **「🌱 상품소싱」**. `aria-disabled`·`title="다음 단계에서 만듭니다"`를 지운다.

**폰 「⋯ 더보기」** — 지금은 `07`·`08b`가 곧장 `업체.html`로 보낸다. 갈 곳이 둘이 됐으니 `04-공통UI.js`에 `더보기시트(지금)`를 하나 만들어 **네 화면이 같이 쓴다**(🏢 업체 관리 / 🌱 상품소싱, `지금` 항목은 초록). 화면마다 제 시트를 만들면 네 벌이 되어 반드시 어긋난다.

## 10. 🔴 `?v=` 올리기 체크리스트 — 하나라도 빠지면 옛 파일이 캐시에서 뜬다

`js`·`css`를 **하나라도** 고쳤으면 **아래 다섯 파일을 전부** `?v=5` → `?v=6`.

- [ ] `v3/index.html`
- [ ] `v3/주문.html`
- [ ] `v3/업체.html`
- [ ] `v3/소싱.html` (새로 만들 때부터 `?v=6`)
- [ ] `v3/이사.html` — 🔴 **지금 `?v=4`로 혼자 뒤처져 있다. 이번에 같이 맞춘다**

`grep -n '?v=' v3/*.html | grep -v 'v=6'` 이 **아무것도 안 뱉어야** 끝난 것이다.

## 11. 다 만든 뒤 직접 눌러볼 것 (`dev-checker`로 넘기기 전)

1. `소싱.html?reset=1` — 폴더 0개·즐겨찾기 목데이터로 열어 **빈 화면 안내글**이 뜨는지

5. 폴더 삭제 → 안의 키워드가 **미분류에 살아 있는지**(지워지면 안 된다)
6. 폰 390px — 가로 스크롤 0 · 폴더 타일 2열 · 폴더 안 ↔ 목록 왕복
7. `index.html`·`주문.html`·`업체.html`에서 「🌱 상품소싱」 메뉴로 실제로 넘어오는지, **폰 더보기 시트**가 세 화면 모두에서 뜨는지
8. 1~3단계 회귀 — 입고·재고·주문·업체·명세서가 안 깨졌는지(`04-공통UI.js`·`공통.css`를 건드렸다)
