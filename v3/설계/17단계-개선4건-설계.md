## 1. 작업중 검색칸 (`06g`)

**상태** — 모듈 변수 `검색글 = ''` 하나 더. `대기카드()`가 `완료보기`와 함께 `''`로 되돌린다.

**DOM 뼈대를 바꾼다** — 지금 `칠하기()`가 `대기칸.innerHTML=''`로 통째로 지운다. 검색칸이 그 안에 있으면 칠 때마다 갈려 **아이폰 한글 조합이 끊긴다**(06a 주석과 같은 사고).
```
대기칸
 ├ .사진거름  (PC: 한 줄 [갈래칩 280px][검색 340px] · 폰: 세로 [갈래칩] / [검색])
 │   ├ 칩자리   ← 칠하기가 다시 채운다
 │   └ .search  ← 대기카드()에서 한 번만 만든다. 칠하기가 안 건드린다
 └ 목록자리     ← 칠하기가 다시 채운다
```
- 검색칸: `u.손대야열림` + `u.조합안전입력(e, fn, 180)` — 06a `검색칸()`과 같은 결. 🔍 `.mag` · 값이 있을 때만 `✕ .지움`(누르면 비우고 칠하기).
- 자리글 `품목코드 · 유통명 · 학명`.
- `대기품목(뺀것)`에 거르기 한 줄 — `납작(품목코드+유통명+학명).indexOf(납작(검색글))`. `납작`은 20a와 같은 정의(소문자·공백 제거)를 06g 안에 둔다.
- **칩 숫자 = 찾은 건수** — `칠하기()`의 `작업수`·`완료수`가 이미 `대기품목()`을 부르므로 거르기를 거기 넣으면 저절로 맞는다. 「완료」를 눌러도 같은 검색어가 걸린다(시안 ②).
- 빈 화면 갈래: 검색 전 둘 다 0 → 지금 문구 그대로, **거름줄 숨김**. 검색 후 0 → 목록자리에 `찾는 품목이 없습니다`(거름줄은 남긴다).
- `<mark>` — 유통명·학명·품목코드에서 **대소문자만 무시한 그대로의 글자**가 걸리면 그 부분만 감싼다(`u.안전` 뒤 감싸기 금지 — 앞뒤 조각을 각각 `u.안전`). 공백 무시로만 걸린 경우는 표시 없이 줄만 남긴다.
- CSS: `.search`·`.mag`·`.지움`은 지금 `주문.css`에만 있다 — `index.html`은 그걸 안 싣는다. 대기칸에 `class:'사진대기'`를 달고 `상품.css`에 **`.사진대기 .search …`·`.사진대기 mark`로 가둬** 시안 값 그대로 옮긴다(`.셈`은 시안에서 안 쓰여 옮기지 않는다).

## 2. 재고 업체 고르기 (`06a`·`06b`)

**계약 유지** — `업체찾기(전부, 다시)` 이름·인자·반환(엘리먼트) 그대로, `상태.업체` = 업체명 문자열 / `''`=전체 그대로. 거르기 쪽(`거르기()`)은 안 건드린다.

**속을 갈아끼운다** — `input+datalist` → `.업체고름 > button.고름상자 + .펼침`
- 셈은 지금 것 그대로(입고 기록에서 업체별 건수, 많은 순).
- 상자: 안 걸림 `🏢 업체 전체 ▼` · 열림 `.열림` `▲` · 걸림 `.걸림` `🏢 그린농원 38건 ✕`.
- 펼침: 첫 줄 `전체 {전부.length}`(단위 없음, 시안대로) → 구분선 → `업체명  N건`. 고른 줄 `.on` + `✓`.
- 고르기 → `상태.업체=이름; 상태.쪽=1; 다시()`. **해제 두 길**: 펼침의 「전체」 · 상자 안 `✕`(`stopPropagation`, 펼치지 않고 바로 해제).
- 닫기: 바깥 누름(`document` pointerdown 한 번 걸고 닫을 때 뗀다) · `Escape` · 고른 뒤. 키보드 ↑↓·Enter (1단계 §11).
- `role="listbox"`/`option` · 상자 `aria-expanded`.
- `datalist`·`#zg-입고업체목록`·`.업체지움`은 지운다 — 남기면 두 벌이 된다.

**자리** (`06b`)
- PC `PC목록` 75~80행: 칩줄 = `[필터칩][flex:1][검색 250px][업체 230px]` 한 줄. `조건.appendChild(목.업체찾기…)` 줄을 지우고 칩줄에 붙인다. 검색 `264px`→`250px`.
- PC 높이 둘 다 `var(--h-btn)`·글씨 `--font-sm` (시안 `.pc .search .inp, .pc .고름상자`).
- 폰 `폰목록` 143~145행: 순서를 **검색 → 업체 → 필터칩**으로 바꾼다(시안). 높이 둘 다 `var(--h-input)`.
- 업체가 0곳이면 지금처럼 빈 `div`(자리를 안 차지).

**CSS** — `상품.css` 243~251(`.업체줄…`)을 시안 `.업체고름`·`.고름상자`·`.펼침` 블록으로 **교체**. `.phone`/`.pc` 접두는 실제 코드에선 `.ph-body .펼침 .it`(폰) / 기본값(PC)으로 옮긴다. `.바뀜`·`.바뀜표`·`.hov`는 시안 표시라 옮기지 않는다.

### 3-2 올린 뒤(올림) 삭제

**자료층 `20a` 새 함수 둘**
- `지울줄(r)` — `v3_주문`에서 `문자주문id === r.id` **∪** (`판매처==='문자'` && `주문번호 === r.올린주문번호`). **서비스 줄도 넣는다.**
  > 🔴 지시는 「문자주문id 같은 줄」이었다. 그런데 서비스 줄(08e `넣어주기`)은 `바탕`에서 주문번호·판매처만 물려받고 **`문자주문id`가 없다.** id로만 지우면 서비스 줄과 그 서비스 출고가 고아로 남아 재고가 빠진 채 남는다. 그래서 `대상줄()`(20a:149)의 범위에서 서비스 제외만 뺀 것으로 정했다.
- `올림지우기(id)` → `{오류}` 또는 `{지운주문수}`
  1. `r.상태 !== '올림'` → 오류
  2. `줄들 = 지울줄(r)` · `나간 = ZG.주문입력.나간줄(줄들)` → 하나라도 있으면 `{오류:'이미 배송완료된 줄이 N개 있어 지울 수 없습니다.'}` (08c 문구 그대로)
  3. `줄들.forEach` → `저.지우기(주문, o.id)` + `ZG.서비스품목.출고지우기(o.id)` (08c 574행과 같은 두 줄)
  4. **맨 끝에** `저.지우기(문자주문, r.id)` — 중간에 끊기면 문자주문 줄이 남아 다시 눌러 남은 것을 마저 지운다
- 기존 `지우기(id)`(저장·보냄용)는 **그대로**.

**`08c`** — `나간줄`을 `ZG.주문입력` export 에 한 줄 더한다. 함수 몸은 안 고친다(규칙이 한 곳에만 있게).

**화면층 `20c` `올림삭제(r)`**
1. 누르자마자 `지울줄`+`나간줄`로 먼저 본다 → 막히면 **토스트만**, 확인창 없음 (08c 건삭제와 같은 순서)
2. 1차 `u.확인` — 지금 문구 그대로(`이 문자주문을 지울까요?` · 이름 · 전화 · `삭제`)
3. 2차 — **`지울줄`이 1줄 이상일 때만.** 제목 `주문 탭의 주문도 지울까요?` · 본문 `주문 탭에 올라간 주문 N건도 함께 지워집니다` + 빨간 줄 `{주문번호} {이름} · {종}종 {개}개 {합}원` · 확인글 `함께 삭제` · 위험. N = `지울줄`의 **서로 다른 주문번호 수**(보통 1)
   - `u.확인`은 두 겹을 막는다(`.askbox` 있으면 안 뜸). 1차 콜백은 상자를 지운 **뒤** 불리므로 콜백 안에서 2차를 바로 부르면 된다
4. `올림지우기` → 오류면 토스트 · 성공이면 `상태.열린=null` · 토스트 `지웠습니다 — 주문 N건 함께` · `다시()`

**자리**

- 빨간 줄 CSS는 `.askbox .지울주문`(주문.css `.문자주문` 절 끝, 시안 값).

### 3-3 서버에 반영되나 — **된다** (코드로 확인)

`저장소.지우기(k,id)`(01:128) → `ZG.보내기.삭제` → 큐 → `v3_` + 표이름(키에서 `zg.v3.` 뗀 것) 에 `{id, 삭제됨:true}` upsert (01c:71). **표 이름은 키에서 바로 나와** `따로표`와 무관하다. 따로 채널(01b:238)은 **받기**만 가른다 — 다른 기기는 `v3-문자주문` 채널로 `삭제됨:true` 를 받아 `받은줄()`(01b:278)이 로컬에서 뺀다. 첫 내려받기도 `삭제됨` 을 걸러낸다(01b:203). 저장·보냄 줄 삭제가 이미 같은 길로 돌고 있다.
주문·출고는 큰 채널(`v3-전체`)로 같은 방식. 표마다 따로 upsert 되어 하나가 실패하면 그 표만 큐에 남아 다음에 다시 간다(01c:76).

## 4. 주문조회 합계 줄 (`08b`·`08o`)

**대상 = 지금 걸린 조건 전체의 `건들`**(쪽 나누기 전). PC 760행 `건들`, 폰 `채우기()` 안 `건들` — 둘 다 `자.건으로묶기(줄들())` 결과다.
- 주문 = `건들.length` · 주문금액 = `Σ g.총액` · 박스 = `ZG.운임손질.박스세기(건들)`
- **`08o`에 `박스세기(건들)` 하나 추가** (읽기만, 저장 안 함)
  - 건마다 기본 1. 그 건 `줄들`의 `묶음id`(빈 값 제외)마다 `목록(묶음id)` 행 중 **이 건 것**을 찾는다:
    `묶음열쇠`가 `이름키(수령인)+'|'+(숫자만(우편번호) || '주소#'+주소압축(주소))+'|'` 로 시작 · 또는 `'홀로#'+줄.주문번호+'#'` 로 시작
  - 찾은 행: `차수 1` 이 있으면 기본 1을 그 `박스수`로 바꾸고, `차수 2↑`(송장 한 장 더)는 각자 `박스수`를 더한다 = 08i `준비()`의 `박스합`과 같은 셈
  - 🔴 **같은 손질 행은 한 번만 센다**(본 행 id 집합) — 08i는 이름+우편+전화, 08b는 이름+전화+주소로 묶어 한 송장이 두 건으로 갈릴 수 있다
  - 🔴 정규화 `이름키`·`주소압축`은 08i 19·20행과 **같은 글자로** 08o 안에 둔다(08i는 안 고친다). 전화 부분은 안 본다 — 원본 27칸의 세 전화 중 무엇이 쓰였는지 주문 줄로는 못 가린다
  - 문자·수동·심폴 주문(`묶음id` 없음)은 늘 1
- **자리**: PC — `카드.appendChild(PC표(이번쪽))` 와 `PC아래줄(건들)` 사이. 폰 — `회차줄` 과 `목록` 사이에 `합계칸` 하나 두고 `채우기()`가 다시 채운다. **0건이면 감춘다.**
- 글: PC `주문 38건 · 박스 41개 · 주문금액 1,284,500원` / 폰 세 칸(주문·박스 왼쪽, 금액 오른쪽). 숫자 `u.콤마`.
- CSS `.합계띠` 시안 값 그대로 — 시안의 `.pc .합계띠` → `.table-card .합계띠`, `.phone .합계띠` → `.ph-body .합계띠`.

## 5. 위험 — 빌더가 놓치기 쉬운 것

| 위험 | 막는 법 |
|---|---|
| 🔴 **올림 삭제는 주문·출고 실데이터를 지운다.** 되살리는 단추가 없다 | 시험은 **로컬(서버 끈 상태)에서 만든 문자주문으로만**. 실서버 줄로 누르지 않는다. 검수표에: 지운 뒤 `v3_주문`에 그 주문번호 줄 0 · 서비스 출고 0 · 재고가 서비스 수량만큼 되돌아옴 |
| 🔴 나간 줄이 있는데 지워짐 | 확인창 **전에** 막는다 + `올림지우기` 안에서 **한 번 더** 막는다(두 기기 사이 틈) |
| 서비스 줄 고아 | `지울줄`이 주문번호로도 잡는다(§3-2). 시험: 서비스 품목 넣은 문자주문을 지우고 주문탭에 그 사람 줄이 안 남는지 |
| 지운 뒤 같은 날 새로 올리면 주문번호 `YYMMDD-NN` 재사용 | `새주문번호()`가 남은 주문만 본다. 로젠 파일·배송완료가 옛 번호를 들고 있으면 엉뚱한 건에 붙을 수 있다 — **고치지 않는다**, 우람님께 가정으로 알린다 |
| 주문탭(08c 건삭제)에서 먼저 지운 문자주문 | 문자주문 줄은 `올림`으로 남는다. 이 화면 삭제를 누르면 `지울줄` 0 → 2차 확인 없이 문자주문 줄만 지운다 |
| 검색칸 DOM 갈림(06g·20c 품목추가) | 칠할 때 **칸은 두고 그 아래만** 갈아끼운다 |
| 업체 펼침이 안 닫힘 · 리스너 쌓임 | 닫을 때 `document` 리스너를 꼭 뗀다. `다시()`로 상자가 갈리면 떼는 것도 같이 |
| `?v=` 안 올림 | §0 표대로. 서비스워커가 옛 판을 계속 낸다 |
| 박스 수가 로젠 파일과 다름 | 08b 건 ≠ 08i 송장 묶음이라 **근사값**이다. 손질 없는 날은 정확히 `건수`와 같다 |

## 6. 가정 (우람님 확인 전, 이대로 만든다)

1. 올림 삭제 범위에 **서비스 줄을 넣는다**(지시는 문자주문id만 — §3-2 이유).
2. PC 발송완료 줄에는 삭제 단추를 안 단다. 폰은 밀리고 토스트로 막힌다.
3. 업체 펼침 「전체」 옆 숫자는 품목 수(단위 없음), 업체 옆은 입고 건수(`건`) — 시안 그대로.
4. 재고 검색칸은 지금 `input` 그대로 두고 폭·자리만 맞춘다(🔍 은 자리글에 이미 있다).
5. 합계 박스 수는 회차 손질의 이름+우편 접두로 맞춘 근사값.
