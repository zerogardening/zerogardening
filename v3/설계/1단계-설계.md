# v3 1단계 설계 — 상품(입고 · 재고)

> 대상: `dev-builder`. **이 문서 하나만 읽고 바로 코딩을 시작할 수 있게** 시안의 클래스명·값을 그대로 옮겨 적었다.
> 시안 파일을 다시 열 필요는 없다. 다만 **마크업을 통째로 베낄 때만** `01-입고-macA.html` · `02-재고-macA.html`을 참고한다.
>
> 확정 시안: `통합관리/v3/시안/00-뼈대-macA.html` · `01-입고-macA.html` · `02-재고-macA.html` · `_공통-macA.css`
> **레이아웃 · 색 · 부품은 컨펌 완료다. 바꾸지 않는다.** 바꿔야 할 이유가 보이면 `dev-manager`에게 알린다.

## 0. 이 설계의 뼈대가 되는 결정 다섯

| 결정 | 왜 |
|---|---|
| **한 덩어리 JSON 저장 금지.** localStorage 키를 표(테이블)마다 하나씩 나눈다 | 지금 프로그램의 최대 결함이다. 나중에 Supabase 테이블로 1:1 옮겨진다 |
| **현재고는 저장하지 않는다.** 입고 · 출고 · 조정 기록에서 매번 계산한다 | 업무규칙 §4. 덧붙이기(append)만 하므로 두 사람이 동시에 고쳐도 서로 덮어쓰지 않는다 |
| **품목코드는 타이핑이 아니라 목록선택** | 실데이터에서 손입력 오류가 대량 확인됐다 (§9) |
| **도구를 새로 넣지 않는다.** 빌드 없음 · npm 없음 · 프레임워크 없음 · `type="module"` 없음 | GitHub Pages에 올리면 그대로 열리고, 로컬에서 `file://`로 더블클릭해도 열려야 한다 |
| **화면 하나당 파일 하나** | 지금 `app.html`이 16,688줄이라 손을 못 댄다 |

## 1. 파일 구성

```
통합관리/v3/
├─ 상품.html                  진입점. 입고 · 재고 두 탭이 한 화면 (시안 .pc-tabs 그대로)
├─ css/
│  ├─ 공통.css                시안 _공통-macA.css 그대로 + §2의 보강분 + §10 애니메이션
│  └─ 상품.css                이 화면 전용 + 반응형 전환
└─ js/
   ├─ 00-시드.js              목데이터 (§5)
   ├─ 01-저장소.js            localStorage 읽기/쓰기 · 시드 · 스키마버전
   ├─ 02-품목코드.js          학명 정규화 · 앞3자 · 일련번호 · 중복판정 · 규격 정규화
   ├─ 03-계산.js              현재고 · 월출고량 · 소진일 · 상태 · 금액
   ├─ 04-공통UI.js            포맷터 · 토스트 · 시트 열고닫기 · 자동완성(.ac) 부품 · 스테퍼
   ├─ 05-입고.js              입고 탭 전체
   ├─ 06-재고.js              재고 탭 전체
   └─ 07-앱.js                부팅 · 탭 전환 · 반응형 재렌더 · storage 이벤트
```

**로드 방식** — `상품.html` 맨 아래에서 번호 순서대로 평범한 `<script src>`. 모듈 아니다.

```html
<script src="js/00-시드.js"></script>
<script src="js/01-저장소.js"></script>
... 07까지 ...
```

**전역은 `ZG` 하나뿐이다.** 각 파일 맨 위에서 `window.ZG = window.ZG || {};` 하고 `ZG.저장소`, `ZG.품목코드`, `ZG.계산`, `ZG.ui`, `ZG.입고`, `ZG.재고`, `ZG.시드`에 붙인다. 그 밖의 전역 변수는 만들지 않는다.

**파일 크기 상한 — 한 파일 400줄.** 넘으면 그 자리에서 쪼갠다(예: `06-재고.js` → `06a-재고목록.js` + `06b-재고수정.js`). 넘긴 채로 넘어가지 않는다.

**폰·PC는 한 벌이다.** 파일을 나누지 않는다. 같은 `상품.html`을 `--bp: 900px` 기준으로 CSS가 갈라 보여준다. 이유 — 데이터·검증·계산 로직이 완전히 같은데 파일을 나누면 두 벌을 고쳐야 하고, 그게 지금 프로그램이 망가진 방식이다.

## 2. 시안 CSS에서 **비어 있는 것** — 반드시 채운다

시안 HTML은 쓰는데 `_공통-macA.css`에 정의가 없다. 그대로 옮기면 스타일이 안 먹는다.

```css
/* ① .chip.warn — 02-재고에서 「품절」·「일시중지」가 쓰는데 정의가 없다 */
.chip.warn{
  background:#FFF8E8; color:#8A5A00; border-color:#F0DDB0;
}
.chip.warn::before{background:#C88A00}

/* ② 화면 전용 CSS 3종 — 시안 <style>에 갇혀 있다. 상품.css로 옮긴다 */
.totrow td{                                   /* 01-입고 합계줄 */
  background:#F7F7F9; font-weight:var(--weight-bold); color:var(--color-text);
  border-bottom:none; border-top:var(--border-width) solid var(--color-border);
}
.qbar{display:flex; align-items:flex-end; gap:var(--space-lg); flex-wrap:wrap}
.qbar .dash{padding-bottom:var(--space-lg); color:var(--color-text-muted)}
td.same{box-shadow:inset var(--bar-width) 0 0 var(--color-accent-border)}
.sub{display:block; font-size:var(--font-2xs); color:var(--color-text-muted);
     font-weight:var(--weight-medium); margin-top:1px}

그 밖에 `--color-*`, `--font-*`, `--space-*`, `--radius-*` 등 시안 `:root` 변수는 **한 줄도 고치지 않고 그대로 가져온다.**

### 3-2. 품목 (`zg.v3.품목`) — 한 건

| 필드 | 타입 | 예 | 설명 |
|---|---|---|---|

| `접두` | string | `"PER03"` | 앞 5자. 중복 검사·묶음의 기준 |
| `학명3` | string | `"PER"` | 앞 3자 |
| `일련번호` | string | `"03"` | 2자리 |
| `규격cm` | number | `15` | 코드 뒤에 붙는 숫자 |
| `규격` | string | `"15cm 포트"` | 화면 표시용 |
| `유통명` | string | `"수크령 '레드헤드'"` | 필수 |
| `학명` | string | `"Pennisetum alopecuroides 'Red Head'"` | |
| `학명키` | string | `"pennisetum alopecuroides 'red head'"` | 정규화본. 같은 식물 판정에 쓴다 (§6) |
| `매입단가` | number | `2800` | 가장 최근 입고 단가 |
| `과세구분` | `"과세"`\|`"면세"` | `"면세"` | 기본 면세 |
| `상태` | `"판매중"`\|`"품절"`\|`"일시중지"` | `"판매중"` | **「재입고 필요」는 저장하지 않는다 — 계산값이다 (§7)** |
| `특성` | object\|null | | 아래 |
| `등록일시` | number | `1785000000000` | `Date.now()` |
| `수정일시` | number | | |

`특성`(선택 · `.fold` 안에서 입력) — `{최대높이, 최대너비, 내한성, 물주기, 햇빛, 개화기, 관리특이사항}`.
전부 문자열이고, 전부 비어 있으면 `특성` 자체를 `null` 로 둔다. (다자란키·다자란폭 → **최대높이·최대너비**로 이름을 바꿨다 · §16-3)
값 안내는 업무규칙 §7. `"Zone5"` · `"보통"` · `"양지"` · `"6~9월"` 처럼 **적은 대로 저장한다** — 1단계는 선택지로 묶지 않는다.
입력 부품은 `js/04b-특성.js` 하나뿐이고 **입고 등록과 재고 수정이 같이 쓴다** (§16-5).

**`현재고` 필드는 없다.** 넣지 마라. §7에서 계산한다.

### 3-3. 입고 (`zg.v3.입고`) — 한 건

| 필드 | 타입 | 예 |
|---|---|---|
| `id` | string | `"rc_" + Date.now().toString(36) + "_" + 랜덤5` |
| `입고일` | string | `"2026-08-04"` — **`YYYY-MM-DD` 외 형식 금지** |
| `입고업체` | string | `"한아름농원"` |
| `품목코드` | string | `"PER03-27"` (FK) |
| `유통명` | string | 입고 시점 값을 그대로 박아둔다 (업무규칙 §4 이름 찾기 순서 1번) |
| `학명` | string | 〃 (2번) |
| `규격` | string | `"27cm 포트"` |
| `수량` | number | `40` |
| `매입단가` | number | `5200` |
| `과세구분` | `"과세"`\|`"면세"` | |
| `메모` | string | `""` |
| `등록일시` | number | `Date.now()` |

**`금액`은 저장하지 않는다.** `수량 × 매입단가`로 그때그때 계산한다.

### 3-4. 출고 (`zg.v3.출고`)

3단계 주문 화면이 붙을 자리다. 1단계는 시드만 넣고 읽기만 한다.
`{ id, 출고일:"YYYY-MM-DD", 품목코드, 수량:number, 출처:"주문"|"시드" }`

### 3-5. 재고조정 (`zg.v3.재고조정`)

**덧붙이기만 한다. 고치거나 지우지 않는다.** 재고 수정에서 현재고를 바꾸면 여기에 한 줄이 쌓인다.
`{ id, 품목코드, 조정수량:number, 조정일시:number(Date.now()), 사유:string }`
`조정수량`은 증감이 아니라 **그 시점에 세어본 실제 수**다.

### 3-6. 업체 (`zg.v3.업체`)

`{ id, 이름, 구분:"공급업체", 마지막사용:number }`
입고업체 칸도 **자동완성 목록선택**이다. 실데이터에서 `정원사의널서리`/`정원사의 널서리`, `성은화훼유통`/`성은화훼유통센터`, `엠케이`/`MK`처럼 같은 업체가 갈라져 있었다(§9). 목록에 없으면 `.ac .new` 줄에서 「새 업체로 등록」한다.

### 3-7. 저장소 규약 (`01-저장소.js`)

```
ZG.저장소.읽기(키)          → 배열/객체. 없으면 [] 또는 {}. JSON.parse 실패 시 [] 반환하고 console.warn
ZG.저장소.덧붙이기(키, 레코드)  → 쓰기 직전에 다시 읽고(재조회) push 후 저장. 반드시 이 방식
ZG.저장소.바꾸기(키, id, 변경객체) → 다시 읽고 해당 id만 Object.assign 후 저장
ZG.저장소.전체쓰기(키, 배열)   → 시드·초기화 전용. 화면 코드에서 부르지 않는다
```

**메모리에 들고 있던 배열을 통째로 다시 쓰지 않는다.** 항상 `읽기 → 한 건만 손대기 → 쓰기`. 다른 탭이 그 사이에 넣은 것을 지우지 않기 위해서다. 이 습관이 그대로 Supabase의 행 단위 insert/update가 된다.

**부팅** — `zg.v3.설정.스키마버전 !== 1` 이거나 `시드완료 !== true` 면 §5를 시드한다.
**초기화** — 주소 뒤에 `?reset=1` 이 붙으면 `zg.v3.*` 키를 전부 지우고 다시 시드한다 (검수자용).
**다른 탭 반영** — `window.addEventListener('storage', …)` 로 `zg.v3.` 로 시작하는 키가 바뀌면 현재 탭을 다시 렌더한다.

## 4. 화면 구성

`상품.html` 한 장 안에 두 탭. `.pc-tabs`의 `입고`/`재고`를 누르면 갈린다.

| 폭 | 뼈대 |
|---|---|
| **≥ 900px (PC)** | 좌 `.pc-side` 사이드바 고정 + 우 `.pc-main`. `.pc-head`(상품 / 상품 › 입고) → `.pc-tabs` → 내용 |
| **< 900px (폰)** | `.ph-top`(큰 제목 28px) → `.ph-sub`(요약줄) → `.ph-body`(스크롤) → `.ph-nav`(하단 탭바 4칸: 입고·재고·주문·더보기). 사이드바 숨김 |

1단계에서 사이드바/하단탭의 **주문 · 명세서 · 업체 · 소싱 · 더보기는 눌러도 아무 일 없다** (`aria-disabled`, 흐리게). 링크를 죽은 곳으로 보내지 않는다.
시안의 `🖥 PC화면으로`(`.pcbtn`) 버튼은 **1단계에서는 넣지 않는다** — 반응형 한 벌이라 갈 곳이 없다.

### 6-2. 학명 정규화 — 이걸 먼저 한다

실데이터에 따옴표가 **세 종류**(`'` U+2019 · `'` U+2018 · `'` U+0027) 섞여 있다. 정규화 없이는 같은 식물을 다른 식물로 본다.

```
함수 학명정규화(원문):
    s = 원문
    s = s의 ' ' ´ ` 를 전부 ' 로 바꾼다      // U+2018 U+2019 U+00B4 U+0060 → U+0027
    s = s의 × 와 x 를 사이 공백과 함께 정리   // "Anemone × hybrida" → "Anemone x hybrida"
    s = 악센트 제거                          // s.normalize('NFD').replace(/[̀-ͯ]/g,'')
    s = 연속 공백 1칸으로, 앞뒤 공백 제거
    반환 s

함수 학명키(원문):                            // 같은 식물인지 판정하는 열쇠
    반환 학명정규화(원문).toLowerCase()
```

### 6-3. 앞 3자 뽑기

```
함수 학명3자(학명):
    s = 학명정규화(학명)
    품종 = s에서 작은따옴표 안 첫 덩어리        // /'([^']+)'/ 의 1번 그룹
    속명 = s를 공백으로 자른 첫 조각의 A-Za-z만 남긴 것

    만약 품종이 있고 품종의 첫 글자가 영문이면:
        코드 = 속명앞2자 + 품종첫글자
    아니면:
        코드 = 속명앞3자

    코드 = 코드.toUpperCase()
    코드가 3자보다 짧으면 뒤를 'X'로 채운다      // 속명이 2자 미만인 이상값 방어
    반환 코드
```

### 6-4. 규격 정규화

```
치환표 = { 4치:10, 5치:15, 6치:18, 7치:21, 9치:27 }

함수 규격정규화(입력):
    입력에서 숫자를 뽑는다
    "치"가 들어 있으면 치환표로 cm 값을 얻는다 (표에 없는 치 → 거절)
    아니면 그 숫자를 cm로 본다
    cm가 1~999가 아니면 거절
    반환 { 규격cm: cm, 규격: cm + "cm 포트" }
```

`.seg` 기본 선택지는 **10 / 15 / 18 / 21 / 27cm** 다섯 + `직접입력`. `직접입력`은 숫자만 받는다(`^\d{1,3}$`). 「1년생」처럼 숫자 없는 값은 거절하고 그 자리에서 이유를 보여준다. 규격 빈칸으로는 저장할 수 없다 — 실데이터에 규격 빈칸이 18건 있었다.

```

    키   = 학명키(학명)

            반환 { 상태:"이미있음", 코드, 기존품목 }
            // 새 품목이 아니라 기존 품목에 대한 재입고다. 코드칸은 잠기고 경고 없음

**화면 연결 (`.alert` + `.pick`)**

- `상태 == "확인필요"` 일 때만 `.alert` 상자를 띄운다.

  - PC는 `.alert` 안에 충돌 품목 표(품목코드·유통명·학명·규격·현재고), 폰은 `<p>`에 코드·유통명만 한 줄

- **품목코드 입력칸은 언제나 `readonly`다.** 손으로 못 친다. `.inp.code` 그대로 두고 `readonly` 속성만 붙인다

```
함수 현재고(품목코드):
    조정 = 재고조정 중 이 품목코드인 것 가운데 조정일시가 가장 늦은 것

    만약 조정이 있으면:
        기준시각 = 조정.조정일시
        시작    = 조정.조정수량
        더한값  = 입고 중 이 품목코드이고 등록일시 > 기준시각 인 것의 수량 합
        뺀값    = 출고 중 이 품목코드이고 등록일시 > 기준시각 인 것의 수량 합
    아니면:
        시작 = 0
        더한값 = 이 품목의 입고 수량 전부 합
        뺀값   = 이 품목의 출고 수량 전부 합

    반환 시작 + 더한값 − 뺀값        // 음수가 나오면 0으로 보여주되 값 자체는 그대로 둔다


함수 월출고량(품목코드):
    경계 = 오늘 − 30일
    반환 출고 중 이 품목코드이고 출고일 >= 경계 인 것의 수량 합


함수 소진일(품목):
    만약 품목.상태 == "일시중지":  반환 { 종류:"판정안함", 표시:"판정 안 함" }
    재고 = 현재고(품목.품목코드)
    만약 재고 <= 0:               반환 { 종류:"소진", 일수:0, 표시:"소진" }
    월 = 월출고량(품목.품목코드)
    만약 월 <= 0:                 반환 { 종류:"출고없음", 표시:"—" }
    일수 = 내림(재고 ÷ (월 ÷ 30))
    반환 { 종류:"일수", 일수, 표시: 일수 + "일" }


함수 소진등급(결과):                 // 시안의 .days d0/d1/d2
    종류가 "소진"          → "d0"    // 빨강
    종류가 "일수" 이고 일수 <= 21 → "d1"    // 빨강
    그 밖                  → "d2"    // 검정


함수 재입고필요(품목):               // .chip.out 을 붙일지
    품목.상태가 "판매중"이 아니면 → 거짓        // 품절·일시중지는 판정 대상이 아니다
    소진등급이 "d0" 또는 "d1" → 참
```

**정렬 기본값 — 소진일 빠른 순**: `d0`(소진) → `d1`·`d2`를 일수 오름차순 → `출고없음` → `판정안함`. 동률이면 품목코드 오름차순.

**표시**
- 표 현재고 칸: 0이면 `td.r.zero`(빨강 굵게), 아래 `<span class="sub">월 N주</span>`
- 소진일 칸: `<span class="days d0|d1|d2">`, 판정안함은 `td.r.dim` + `font-weight:var(--weight-medium)`
- 상태 칸: 재입고필요 → `.chip.out` 「재입고 필요」 / 품절·일시중지 → `.chip.warn` / 그 밖 → `.chip` 「판매중」
- `.ph-sub` 요약: `등록 N종 · 총 N주` / `3주 내 소진 N종`
- `.alert` 「3주 안에 소진」: 재입고필요 품목을 소진일 순으로, **PC는 `.ucard` 5장까지** 「나머지 N종은 아래 목록에서」, **폰은 `.ph-card` 3장까지** 「전체 ›」

**`.ucard` 안**: `.days`(가장 큰 글씨) / `.nm` 유통명 + `.code` 품목코드 / `.sci` 학명 · 규격 / `.stock` 현재고 + `.sub` 월 N주 나감 / `.last` 마지막 입고일 / `.btn.sm` 「입고 등록」 → 입고 탭으로 가면서 그 품목을 채운다.

**「3주 내 소진」 필터칩** `.fchip.alert` 은 재입고필요 품목만 남긴다.

**금액** — `수량 × 매입단가`. 화면 표기는 `toLocaleString('ko-KR')` 로 세 자리 콤마. 입력칸도 blur 시 콤마를 붙이고, 읽을 때는 콤마를 떼고 `Number()`.

## 10. 애니메이션

### 10-1. CSS 변수 — `공통.css` 의 `:root` 에 넣는다

```css
:root{
  /* ── 가속 곡선 ── */
  --ease-ios:    cubic-bezier(.32,.72,0,1);    /* 시트 · 큰 이동. iOS 기본 느낌 */
  --ease-out:    cubic-bezier(.2,.8,.3,1);     /* 나타남 */
  --ease-in:     cubic-bezier(.4,0,1,1);       /* 사라짐 */
  --ease-spring: cubic-bezier(.34,1.3,.64,1);  /* 스테퍼 숫자가 톡 튀는 정도 */

  /* ── 시간 ── */
  --dur-tap:    100ms;   /* 버튼 눌림 */
  --dur-fast:   150ms;   /* 색·테두리 바뀜 */
  --dur-list:   200ms;   /* 목록 한 줄 페이드 */
  --dur-exit:   220ms;   /* 시트 · 화면 나감 — 들어올 때보다 빠르게 */
  --dur-scrim:  240ms;   /* 스크림 */
  --dur-tab:    250ms;   /* 탭 인디케이터 */
  --dur-enter:  320ms;   /* 시트 · 화면 들어옴 */
  --dur-toast: 2600ms;   /* 토스트가 떠 있는 시간 */

  /* ── 거리 · 배율 ── */
  --scale-tap:   .96;    /* 눌렀을 때 */
  --sheet-x:     100%;   /* PC 시트가 오른쪽에서 들어오는 거리 */
  --view-y:      16px;   /* 폰 화면 전환 때 살짝 올라오는 거리 */
  --list-y:      8px;    /* 목록 줄이 들어올 때 */
  --stagger:     24ms;   /* 목록 줄 사이 시차 (최대 6줄까지만) */
}
```

### 10-2. 어디에 쓰나

| 곳 | 무엇 | 값 |
|---|---|---|
| 모든 `.btn` · `.fchip` · `.seg button` · `.stepper button` · `.ph-save` `:active` | `transform:scale(var(--scale-tap))` | `--dur-tap` `--ease-out` |
| 〃 `:hover`, `.on` 붙고 떨어짐 | `background` · `border-color` · `box-shadow` | `--dur-fast` `--ease-out` |
| `.editpanel` 들어옴 | `transform: translateX(var(--sheet-x)) → 0` | `--dur-enter` `--ease-ios` |
| `.editpanel` 나감 | `transform: 0 → translateX(var(--sheet-x))` | `--dur-exit` `--ease-in` |
| `.editscrim` | `opacity 0 ↔ 1` | 들어옴 `--dur-scrim`, 나감 `--dur-exit` |
| 폰 상세 화면 들어옴 | `opacity 0→1` + `translateY(var(--view-y))→0` | `--dur-enter` `--ease-ios` |
| 폰 상세 화면 나감 | 반대 | `--dur-exit` `--ease-in` |
| `.pc-tabs` 인디케이터 | 흰 알약(`.on`의 배경)이 미끄러진다 — `.pc-tabs` 안에 절대배치 `::after`나 별도 `<i class="ind">`를 두고 `transform:translateX()` | `--dur-tab` `--ease-ios` |
| `.ph-nav` 탭 전환 | 글자색만 `--dur-fast`. 움직이지 않는다 |
| `.ac` 후보 목록 뜸 | `opacity 0→1` + `translateY(-4px)→0` | `--dur-list` `--ease-out` |
| `.alert` 중복경고 뜸 | `opacity 0→1` + `translateY(-6px)→0` | `--dur-list` `--ease-out` |
| 목록(`.ph-card` · `<tr>` · `.ucard`) 등장 | `opacity 0→1` + `translateY(var(--list-y))→0`, 앞 6줄만 `--stagger` 시차 | `--dur-list` `--ease-out` |
| 저장 직후 그 줄 하이라이트 | `background`가 `--color-accent-bg` 에서 투명으로 | `600ms` `--ease-out` |
| `.stepper .num` 숫자 바뀜 | `transform: scale(1.12) → 1` | `--dur-fast` `--ease-spring` |
| 검사 실패한 칸 | shake — `translateX: 0,-5px,5px,-3px,3px,0` | `280ms` `--ease-out` |
| 토스트 | 들어옴 `opacity 0→1` + `translateY(12px)→0` `--dur-enter`, 나감 `--dur-exit`. `--dur-toast` 뒤 자동 사라짐 | |
| `.fold` 펼침 | `grid-template-rows: 0fr → 1fr` + `opacity` | `--dur-list` `--ease-out` |

### 10-3. 지켜야 할 규칙

- **`transform` 과 `opacity` 만 애니메이트한다.** `height` · `top` · `left` · `width` · `margin` 은 쓰지 않는다 (`.fold` 는 `grid-template-rows` 예외 — 이건 합성 대상이라 안전하다)
- **`will-change` 는 움직이기 직전에만 붙이고 끝나면 뗀다.** 상시로 걸어두지 않는다
- **목록 전체 재렌더에는 시차를 주지 않는다.** 앞 6줄까지만. 126종이 하나씩 나타나면 느려 보인다
- 시트가 열려 있는 동안 `body`(또는 `.pc-main`)에 `overflow:hidden`
- 애니메이션이 끝나기 전에 같은 요소를 다시 부르면 **먼저 것을 취소한다** (`Element.getAnimations().forEach(a=>a.cancel())`)

### 10-4. 움직임 끄기 — 반드시 넣는다

```css
@media (prefers-reduced-motion: reduce){
  *, *::before, *::after{
    animation-duration:.01ms !important;
    animation-iteration-count:1 !important;
    transition-duration:.01ms !important;
    scroll-behavior:auto !important;
  }
}
```

**끄더라도 결과 상태는 똑같아야 한다.** 시트는 여전히 열리고, 목록은 여전히 바뀐다 — 움직임만 없다.
JS에서 `Element.animate()` 를 쓸 때도 같은 조건을 검사한다:
```js
const 움직임끔 = matchMedia('(prefers-reduced-motion: reduce)').matches;
const 시간 = 움직임끔 ? 0 : 320;
```

## 15. PWA — 아이폰 홈화면에 설치 (우람님 8/4 추가 지시)

**진입점을 바꾼다.** `상품.html`이 아니라 `통합관리/v3/index.html`이 진입점이다. 주소가 `.../v3/`로 깔끔하게 열려야 한다.
`index.html`은 지금 만드는 `상품.html`과 같은 내용이거나(1단계엔 화면이 이거 하나뿐이니), `상품.html`을 그대로 `index.html`로 이름 짓는다. 파일 하나면 된다 — 굳이 리다이렉트용 껍데기를 또 만들지 마라.

### 15-1. manifest.json (`통합관리/v3/manifest.json`)

```json
{
  "name": "제로가드닝 통합관리",
  "short_name": "통합관리",
  "start_url": "./index.html",
  "scope": "./",
  "display": "standalone",
  "background_color": "#F5F5F7",
  "theme_color": "#2F9E44",
  "icons": [
    { "src": "icons/icon-180.png", "sizes": "180x180", "type": "image/png" },
    { "src": "icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icons/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
```

### 15-2. 아이콘

`통합관리/logo.png`(600×400, 로고)를 바탕으로 180·192·512px **정사각형** 아이콘 3장을 `통합관리/v3/icons/`에 만든다. 로고가 가로로 길어서 그대로 정사각형에 넣으면 잘리거나 여백이 어색할 수 있다 — **초록(`#2F9E44`) 바탕에 로고를 가운데 배치**(여백을 넉넉히 두고 축소)하는 방식으로 3장 다 같은 구도로 만든다. `sips`로 리사이즈하면 된다(빌드 도구 없이).

### 15-3. `index.html` `<head>`에 넣을 것

```html
<link rel="manifest" href="manifest.json">
<meta name="theme-color" content="#2F9E44">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="default">
<meta name="apple-mobile-web-app-title" content="통합관리">
<link rel="apple-touch-icon" href="icons/icon-180.png">
<meta http-equiv="Cache-Control" content="no-cache">
```

### 15-4. Safe area — 노치·홈바에 화면이 먹히면 안 된다

`standalone`으로 열리면 시안의 가짜 iOS 상태바(`.ios-status`, 이미 §1에서 뺐다)가 있던 자리에 **진짜** 아이폰 상태바가 온다. `.ph-top`과 `.ph-nav`에 안전영역 여백을 더한다:

```css
.ph-top{ padding-top: calc(var(--pad-ph-top-y, 10px) + env(safe-area-inset-top)); }
.ph-nav{ padding-bottom: calc(8px + env(safe-area-inset-bottom)); }
body{ padding-left: env(safe-area-inset-left); padding-right: env(safe-area-inset-right); }
```
정확한 변수명은 시안 `.ph-top`/`.ph-nav` 기존 padding 값에 `env()` 만큼을 **더하는 식**으로 건드린다. 기존 값 자체를 지우지 않는다.

### 15-5. 🔴 Service Worker는 넣지 않는다

개발 중 캐시가 끼어 옛 화면이 계속 뜨는 사고를 막기 위해서다. `sw.js` 등록 코드를 넣지 마라. 오프라인 지원은 이번 범위가 아니다.
CSS·JS 파일이 여럿이니 `<script src="js/00-시드.js?v=1">`처럼 **버전 꼬리**를 붙여, 나중에 값을 바꿔가며 캐시를 무효화할 수 있게 해둔다(지금은 전부 `?v=1`).

### 15-6. GitHub Pages 도메인

지금 저장소가 Pages로 나가는 도메인 그대로다(별도 도메인을 새로 사지 않는다). `.../v3/`로 접속해 홈화면에 추가하면 아이콘 없이도 설치는 된다 — 아이콘은 이번에 채운다.
**작업 중에도 계속 수정·배포 가능하다** — push할 때마다 Pages가 다시 반영되고, 이미 설치된 홈화면 앱도 다음에 열 때 새 버전을 받는다(Service Worker가 없으니 캐시에 갇히지 않는다).

`index.html` `<head>` 에 `icons/` 아이콘을 `<link rel="icon">` 으로 건다. 없으면 콘솔에 404가 남는다.

### 16-7. 「3주 안에 소진」 → 「재입고 요청」 접기칸 (우람님 8/4 지시)

§4-2 · §7 의 `.alert` 「3주 안에 소진」 상자를 **접기식**으로 바꾼다. PC · 폰 같다.

- 제목은 **「재입고 요청」**. 필터칩 「3주 내 소진」과 `.ph-sub` 요약줄은 필터 이름이라 그대로 둔다
- 부품은 새로 만들지 않는다 — `04b-특성` 이 쓰는 **`.fold`(머리) + `.foldbody > div`(몸)** 를 그대로 쓴다. `06a-재고목록.js` 의 `급한카드들()` 하나만 고치면 PC · 폰에 다 반영된다
- **평소엔 접혀 있고** 머리글 한 줄만 보인다 — `＋ 재입고 요청 <span class="n">N종</span>`. 펼치면 `－` 로 바뀌고 `aria-expanded` 도 따라간다
- **N이 0이면 상자에 `.quiet` 를 붙여 무채색**으로 (급할 게 없다). 이전엔 0종이면 상자를 아예 안 그렸는데, 이제는 자리를 지켜 늘 같은 곳에 있게 한다
- 펼침 `--dur-enter` `--ease-ios` / 접힘 `--dur-exit` `--ease-in` — §10-3 이 허용한 `grid-template-rows` 방식 그대로 (`상품.css` 의 `.alert > .foldbody`)
- 「3주 내 소진만 보기」(폰은 「전체 ›」) 단추는 머리글 안에 두면 단추 안 단추가 되므로 **몸 맨 아래**(`.재입고끝`)로 내렸다
- 열림 상태는 `재고목록.상태.급열림` 에만 둔다(저장하지 않는다). **앱을 새로 열면 늘 접힌 채로 시작**하고, 그 세션 안에서 다시 그릴 때만 유지한다 — 밭에서는 목록이 먼저다
