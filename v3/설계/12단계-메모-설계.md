## 0. 우람님 수정 두 가지 — 시안 원본보다 이것이 이긴다

### 0-1. 도구줄에서 「글씨색」과 「하이라이트」를 눈으로 가른다

| 단추 | 아이콘 | 왜 |
|---|---|---|
| **하이라이트** | 노란 박스 안에 **「가」** | 칠해진 모양 그대로 보인다 |
| **글씨색** | **「가」 + 그 아래 색줄** | 지금 고른 색이 그 줄에 뜬다 |

옛 시안은 둘 다 「가+색줄」이라 색만 달랐다 — 밭에서 못 가린다.

### 0-2. 화면에 안내·설명·힌트 문구를 넣지 않는다

**칸 이름과 버튼 글자만 둔다.** 우람님이 콕 집으신 것 셋을 포함해 아래를 전부 뺐다.

| 뺀 것 | 어디 |
|---|---|
| 「쓰던 이름이 뜹니다」 | 폴더 칸 라벨 옆 (폰·PC) |
| 「첫 줄이 제목이 됩니다」 | 편집기 위 (폰·PC) |
| 「기록한 날 12일」·「12일째」 | 영농일지 요약줄 |
| 「자동 저장됨」 | 폰 요약줄 · PC 카드 머리 |
| 「사진은 본문 안에 들어갑니다」 | PC 도구줄 오른쪽 |
| 「메모와 같은 편집기입니다」 | 영농일지 작업내용 라벨 옆 |
| 달력 범례(「기록 있는 날」·「초록칸 = 고른 날」) | 폰·PC 달력 아래 |

| 요약줄 「· 할일 4」 | 바로 밑 거르개 칩에 같은 숫자가 있다 |

🔴 **남긴 것** — 칸 이름(`폴더`·`진행상황`·`날씨`·`작업내용`·`특이사항`) · 버튼 글자 · 검색칸 placeholder(`메모 검색`) ·
**거르개 칩 위의 숫자**(`전체 18`·`밭일 7`) — 그건 설명이 아니라 그 단추가 무엇을 걸러 주는지의 값이다 ·
**날짜·시각 표시**(`2026-08-18 (화) 14:20`·`고친때 18:02`) — 데이터다 ·
**폰 요약줄 왼쪽/오른쪽**(`2026년 8월` · `메모 18건`) — 다섯 화면이 다 쓰는 공통 부품이라 메모만 비우면 어긋난다.

🔴 **시안 파일을 내가 직접 고치고 png를 다시 뽑았다**(`12-메모-macA.html` 788→785줄). 시안과 설계가 어긋난 채 남지 않는다.

### 0-3. 🔴 확정 설계에서 내가 두 가지를 바꿨다 — 그대로 두면 배포날 터진다

| 확정본 | 바꾼 것 | 왜 |
|---|---|---|
| 목록 위 `<input type="month">` | **`‹ 2026.08 ›` 화살표 두 개** | **맥 사파리·파이어폭스는 `type=month`를 지원하지 않는다**(caniuse 기준 전 버전 미지원). 그냥 글자칸으로 떨어져 우람님이 「2026-08」을 손으로 치셔야 한다. 아이폰은 되지만 **PC 화면이 맥이다.** 영농일지 달력 머리가 이미 같은 화살표 부품을 쓰므로 부품이 하나 줄기까지 한다 |
| Storage 버킷 `'메모'` | **버킷 이름 `memo`** | **Supabase 버킷 이름은 소문자 영문·숫자·하이픈만 받는다**(AWS S3 규약). 한글 버킷은 만들어지지 않는다. `현재상태.md`에 이미 적힌 「함수 슬러그에 한글을 쓰면 안 된다」와 같은 부류다. **표 이름 `v3_메모`는 그대로 간다** — 그건 Postgres라 한글이 잘 돈다 |

파일 경로도 전부 ASCII로 짓는다(`2026/08/{메모id}/{난수}.jpg`) — 유니코드 파일명은 Storage에서 사고가 잦다.

## 1. 자리 — 탭바를 한 곳으로 합치는 것이 이 단계의 절반이다

**폰 아래 탭 4칸 → 5칸** `입고 · 재고 · 주문 · 메모 · ⋯더보기`
**PC 왼쪽 메뉴 4줄 → 5줄** 맨 아래 `📝 메모` (명세서는 사이드바에 없다 — 업체 관리 안 탭이다)

🔴 지금 **탭바를 네 곳이 각자 만든다** — `07-앱.js:100` · `08b-주문목록.js:169` · `12-업체앱.js:104` · `14-소싱앱.js:98`.
**PC 사이드바도 똑같이 네 곳이다** — `07:35` · `08b:192` · `12:27` · `14:29`.
다섯 번째를 넣으려면 여덟 군데를 고쳐야 한다. 여섯 번째가 오면 열 군데다.

→ **`04-공통UI.js`에 `u.탭바(지금, 눌림)`과 `u.옆메뉴(지금)` 둘을 만들고 여덟 곳을 한 줄씩으로 줄인다.**
`더보기시트()`가 이미 같은 이유로 거기 합쳐져 있다. 그 옆에 나란히 둔다.
**앞으로 탭이 늘 때 고칠 데는 `04-공통UI.js` 한 곳뿐이다.**

- 각 화면은 `u.탭바('메모')` 한 줄. 상품 화면만 입고·재고가 **페이지 안 탭 전환**이라 `눌림` 되부름을 하나 넘긴다(§세부설계 §2)
- 넷(입고·재고·주문·메모) 중에 없는 이름(`'업체'`·`'소싱'`)을 주면 **더보기 칸이 켜지고** 그 값이 `더보기시트(지금)`로 그대로 넘어간다 — 지금 네 곳의 동작과 정확히 같다
- 🔴 **`08b`는 탭바 높이를 재서 총액바를 올린다**(`08b:184`). 그래서 `탭바()`는 **만든 `<nav>` 요소를 돌려준다.** 붙이는 것은 부르는 쪽이 한다

## 2. 화면 ① 메모

목록과 편집기다. **PC는 좌우 두 칸**(왼쪽 목록 380px · 오른쪽 편집기), **폰은 목록 → 쓰기 두 화면.**

- **날짜 머리글**(`8월 18일 (화)  3건`) 아래로 카드가 쌓인다. **최신순**
- 카드 = 제목 · 시각 · 폴더칩 · 상태칩 · 본문 2줄 미리보기 (+ 사진 썸네일 한 장)
- **제목 칸이 없다.** 본문 첫 줄이 곧 제목이다
- 위에 `메모 검색` 칸 + `‹ 2026.08 ›` (§0-3)
- 거르개 칩 두 줄 — ①폴더 `전체 / 밭일 / 거래처 …` ②진행상황 `할일 / 하는중 / 끝`. 한 번 더 누르면 꺼진다
- 새로 쓰기 — 폰은 오른쪽 아래 **＋(FAB)**, PC는 칩 줄 오른쪽 `＋ 새 메모`

### 폴더
텍스트 칸 **하나**다. `<datalist>`로 쓰던 이름이 뜨고, 새 이름을 치면 그게 새 폴더다.
**폴더 관리 화면은 없다.** 목록은 쓰인 폴더를 세어 칩 줄을 만든다 — 아무도 안 쓰는 폴더는 저절로 사라진다.

### 진행상황
`할일 · 하는중 · 끝` **셋뿐이고 안 고를 수도 있다**(기본값은 없음 — 그냥 적어 두는 메모가 대부분이다).
🔴 **`할일`만 살구색**, 나머지는 무채색이고 `끝`은 가장 조용하다. **빨강은 안 쓴다** — 재고의 「재입고 필요」와 급한 정도가 다르다.

## 3. 화면 ② 영농일지

**하루에 한 장이다.** 달력에서 날을 고르면 그날 일지가 열린다.

- 월 격자 달력(7열) · 기록 있는 날에 점 · 오늘은 테두리 · 고른 날은 초록칸
- 칸은 넷 — `날짜`(달력이 정한다) · `날씨` · `작업내용` · `특이사항`
- **날씨는 칩 5개** `맑음 흐림 비 눈 바람`. 🔴 저장값은 **낱말만**(`'맑음'`) — 이모지는 화면에서만 붙인다
- **작업내용 = 본문.** 메모와 **같은 편집기 한 벌**을 쓴다(사진도 같다)
- **특이사항**은 아래 평문 한 칸(`<textarea>`) — 서식도 사진도 없다
- 🔴 **영농일지에 폴더를 안 띄운다** — 축이 날짜라 겹친다. 진행상황도 없다

🔴 **그날 일지는 하나뿐이다.** id를 `일지-2026-08-18`로 못박아 같은 날에 두 장이 생길 수 없게 한다(§6).

## 4. 편집기 — 새 라이브러리 0개

`contenteditable` + `document.execCommand`. 도구줄은 **다섯**이고 그 이상 넣지 않는다.

| 단추 | 무엇 |
|---|---|
| **B** | 볼드 |
| **가 크기** | 보통 → 크게 → 아주크게 순환 |
| **가 + 색줄** | 글씨색 (팔레트 5색) |
| **노란 가** | 하이라이트 (팔레트 4색 + 지우기) |
| **📷** | 사진 |

- 🔴 **붙여넣기는 평문으로 강제한다.** `paste`를 가로채 `insertText`로 넣는다. 카페24·엑셀에서 복사한 표와 색이 통째로 딸려 들어오면 본문이 걷잡을 수 없어진다
- 🔴 **`execCommand`는 폐기예정 API다.** `17-메모.js` 안 **`서식()` 한 함수에만** 가두고 `ponytail:` 주석으로 올라갈 길(Selection API + Range)을 적어 둔다. 부르는 자리가 흩어지면 나중에 못 갈아탄다
- 🔴 도구줄 단추는 `mousedown`에서 `preventDefault()` — 안 하면 **누르는 순간 본문 선택이 풀려** 아무 데도 적용되지 않는다
- 저장은 **저장 단추**가 진실이다. 그 위에 **조용한 자동저장**(3초 멈추면 · 화면을 뜰 때)이 얹힌다 — **화면에는 아무 표시도 안 낸다**(§0-2). 밭에서 전화가 와도 적던 것이 안 날아간다
- 🔴 **본문이 빈 채로는 아무것도 만들지 않는다** — 새 메모를 열었다 그냥 나가면 빈 줄이 쌓인다

## 5. 사진

`ZG.서버.클라이언트.storage.from('memo').upload(...)` — supabase-js는 `js/01b-서버.js:9`에 이미 붙어 있다.

- 🔴 **올리기 전에 canvas로 줄인다 — 긴 변 1600px, JPEG 0.8.** 아이폰 원본은 한 장에 3~5MB다
- 🔴 **회전을 먼저 편다.** `createImageBitmap(파일, { imageOrientation:'from-image' })` — 안 그러면 아이폰 세로 사진이 눕는다
- 🔴 **localStorage에 사진을 넣지 마라.** 거기엔 품목·주문·명세서 실데이터가 들어 있고, 한 장만 넣어도 5MB 상한이 무너져 **그날 업무가 통째로 멈춘다.** base64도 안 된다
- 본문에는 **경로만** 박는다(`<img data-경로="2026/08/…">`). 그릴 때 서명 URL(1시간)을 **한 번에 묶어** 받아 `src`에 꽂는다
  - 왜 공개 버킷이 아닌가 — ①URL 하나가 새면 영구 공개다 ②본문에 URL을 박아 두면 프로젝트·버킷이 바뀔 때 지난 메모의 사진이 전부 깨진다
- 사진을 지우면 본문과 `사진들`에서 뺀다. **Storage 파일은 그대로 둔다**(되돌릴 길을 남긴다). `ponytail:` 고아 파일 청소는 눈에 거슬릴 때
- 🔴 **인터넷이 안 닿으면 사진은 안 붙는다.** 글은 그대로 저장된다 — 토스트로만 알린다

## 6. 데이터 — 표 하나, 한 줄이 한 장

```js
{ id, 종류, 날짜, 제목, 본문, 사진들, 만든때, 고친때,
  폴더, 상태,        // 메모만
  날씨, 특이사항 }   // 영농일지만
```

| 칸 | 값 |
|---|---|
| `id` | 메모 `m-{36진수시각}-{난수4}` · 일지 **`일지-YYYY-MM-DD`**(그날 한 장을 못박는 열쇠) |
| `종류` | `'메모'` \| `'일지'` — 두 탭이 이 한 칸으로 갈린다 |
| `날짜` | `'2026-08-18'`. 목록 머리글·달력·월 거르개가 전부 이것만 본다 |
| `제목` | 본문 첫 줄에서 뽑아 **저장해 둔다**(목록이 매번 HTML을 파싱하지 않게). 최대 60자 |
| `본문` | 편집기 HTML 문자열 |
| `사진들` | `['2026/08/m-…/a1b2.jpg', …]` — 썸네일과 정리용 |
| `폴더`·`상태` | 메모만. 빈 문자열 허용 |
| `날씨`·`특이사항` | 일지만 |

- 🔴 **한 덩어리 JSON이 아니다.** 메모 한 장이 한 행이라 두 사람이 다른 메모를 같은 시각에 저장해도 서로를 안 덮는다
- `js/01-저장소.js:32` 키에 **`메모: 'zg.v3.메모'` 한 줄.** PK가 기본값 `id`라 `표키`(01-저장소:54)는 안 건드린다
- `js/01b-서버.js:11` `표들`에 **`'메모'` 한 낱말** → 서버 표는 `v3_메모`로 저절로 붙는다
- 🔴 `js/01b-서버.js:135` **다시그리기 목록 `['앱','주문','업체앱','소싱앱']`에 `'메모앱'`을 넣는다** — 안 넣으면 두용씨가 폰에서 적은 메모가 우람님 화면에 안 뜬다. 이 줄을 빠뜨리는 것이 이 단계에서 가장 조용한 사고다
- **이사할 옛 데이터가 없다.** 백업 JSON 24종에 메모·일지에 해당하는 것이 하나도 없다(`데이터현황.md`). `99-이사.js`·`00-시드.js`는 **한 바이트도 안 건드린다**

### 만들 것 (§세부설계 §7에 전문)
`v3_메모` 표 하나 + Storage 버킷 `memo` 하나. 🔴 **우람님이 먼저 돌리셔야 push한다** — 표가 없으면 `표받기('메모')` 404가 다른 표까지 못 내려오게 만든다.

## 9. 검증

1. 새 메모 → 본문 첫 줄이 **목록 카드 제목**으로 뜨는가 · 날짜 머리글 아래 최신순인가
2. 폴더에 없던 이름을 치고 저장 → **칩 줄에 새 폴더가 생기는가** · 새로고침 뒤에도 남는가
3. 진행상황 칩을 한 번 더 눌러 **끌 수 있는가** · `할일`만 살구색인가
4. 검색·`‹ ›` 달 이동·폴더칩·상태칩을 **겹쳐 걸어도** 목록이 맞는가
5. 붙여넣기 — 카페24 주문표를 복사해 붙였을 때 **평문으로만** 들어오는가
6. 도구줄 다섯이 **선택한 글자에만** 걸리는가(누를 때 선택이 안 풀리는가) · 하이라이트와 글씨색 아이콘이 갈리는가
7. 아이폰 세로 사진 → **눕지 않는가** · 파일이 1600px 아래로 줄었는가 · 새로고침해도 사진이 보이는가
8. 🔴 **localStorage 크기가 사진 때문에 늘지 않는가**(`JSON.stringify(localStorage).length`를 사진 넣기 전후로 잰다)
9. 비행기모드에서 사진 첨부 → **글은 저장되고** 사진만 실패하는가
10. 영농일지 — 같은 날을 두 번 열어 저장해도 **한 장인가**(달력 점 하나) · 달을 넘겨도 점이 맞는가
11. 🔴 **탭바·사이드바를 합친 뒤** 상품·주문·업체·소싱 네 화면이 **여전히 멀쩡한가** — 폰 탭 이동, 주문 화면 **총액바가 탭바 위에 제 높이로 앉는가**, 더보기 시트가 업체·소싱에서 제 항목을 켜는가
12. 다른 기기에서 메모를 저장 → **이 화면이 저절로 다시 그려지는가**(01b:135)
13. 화면 어디에도 **안내·설명·힌트 문구가 없는가**(§0-2)
