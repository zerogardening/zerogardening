# 26단계 — 주문탭 「예약」 하위탭 · 자동 올림 설계

시안 `시안/26-예약관리-macA.html` + 우람님 수정(10/20): **새 메뉴 없음** — 주문탭 상태 하위탭 다섯째 「예약」.
데이터·저장소 규약은 18단계 설계 §1 그대로(예약 = `v3_문자주문` 한 줄의 `예약`·`예약일`). **새 표·SQL 없음.**

## 1. 데이터 — 칸 하나만 더한다

| 칸 | 뜻 |
|---|---|
| `자동` `{기기, 때}` | 자동 올림이 이 줄을 잡았다는 표. 두 기기 겹침 막기(§3) + 「오늘 자동으로 올라감 n건」 셈 |

`예약`은 올린 뒤에도 남는다(지금도 그렇다) → 주문 줄 `문자주문id` → 그 줄 `예약===true` 면 **「📅 예약에서 옴」**.
못 올라감은 **저장하지 않고 그때그때 판정**한다(`20e 사유(r)`): 예약일 ≤ 오늘 이고
받는 분 이름 빔 / 주소 빔 / 품목 없음. 주소를 채우면 저절로 빠진다.

## 2. 파일

| 파일 | 할 일 |
|---|---|
| `20a` | `올릴수있나` — 확인창을 지난 줄(`잠금풀기(id)`, 메모리)은 예약일 전이라도 된다. 잠금 판정이 이 한 곳이라 20c·20d·20e 가 다 따라온다 |
| `20e` | `사유` · `자동올리기()` · `서버읽기(ids)`(기존 `서버확인`이 이걸 쓰게 쪼갬) · `예약점표` 삭제 |
| `20g-예약탭.js` (새) | 예약 탭 화면(폰 카드·PC 표) · 지금 올리기 확인창 · 주소 입력(20d `판` 재사용) · 날짜 저장 · 옴칩 · 토스트 · 시작 때 자동 |
| `08b` | 상태칩목록 다섯째 · 탭 수 · 폰/PC 채우기 갈래 · 거르개·날짜줄 숨김 · 뽑기 막기 · 옴칩 2곳 · 주문수집하기 첫 줄 |
| `20c`·`20f` | **문자주문 탭의 예약 갈래를 걷는다**(새 탭과 두 벌) — 갈래칩·폰구역·PC구역·예약판 분기·예약 달력. 펼친 판 예약칸·넘기기창·원본판은 그대로 |
| `01b` | `서버.준비` = 첫 내려받기 약속(한 줄) — 자동 올림이 받은 뒤에 돈다 |
| `css/주문.css` | `.예약탭` 아래로 가둔다(시안 `.rc .nm .dd .st` 가 흔한 이름) · 걷은 갈래 CSS 삭제 |

넘기기창(주문 → 예약) 뒤에는 문자주문 탭 대신 **주문탭 예약 탭**으로 가서 옮긴 줄을 테두리로 보인다.

## 3. 자동 올림 — 앱이 뜰 때(`서버.준비` 뒤) · 📥 주문수집 누를 때

대상 = 예약일 ≤ 오늘 · 사유 없음. 올리기는 **기존 함수만** — 원본줄들 있으면 `20e 되살리기`, 없으면 `20a 주문올리기(id, 줄의 사람칸)`.
줄 모양이 한 벌로 남는다. 상주 도구(Python)는 **안 만든다** — 앱을 하루 한 번은 여시고, 안 열면 올라가도 볼 사람이 없다.

두 기기 겹침 (서버가 있을 때만):
1. 서버에서 그 줄들을 되읽는다 — 서버가 이미 올림·삭제·예약 해제거나 **로컬과 `수정일시`가 다르면**(아직 못 받음) 이번엔 건너뛴다. 남이 1분 안에 `자동`을 찍었으면 건너뛴다
2. `자동 = {이 기기, 지금}`을 쓰고 서버에 닿았는지 되읽는다(1초 간격 3번)
3. 1.5초 쉬고 **한 번 더** 되읽어 아직 내 것인 줄만 올린다 — 동시에 찍었으면 나중에 닿은 쪽만 남아 한 기기만 올린다
- ponytail: 서버 쪽 잠금(조건부 update)이 아니라 되읽기다. 두 쓰기가 1.5초 넘게 벌어지며 엇갈리면 뚫린다 — 겹치면 그때 RPC 로
- 서버가 없으면(로컬 시험) 1~3 없이 바로 올린다. 서버에 못 닿으면 안 올리고 다음 번에

토스트: 올린 게 있을 때만 「📅 예약 N건이 주문탭에 올라왔습니다」 + 못 올라감 있으면 둘째 줄 「M건은 못 올라감 · 확인」(누르면 예약 탭).

## 4. 화면 (시안 26 그대로, 다른 것만)

- 탭: `전체 · 배송준비중 n · 배송완료 · 배송보류 · 예약 n` — n = 예약 전체 수
- 칩 `전체 · 예약일 지정 · 날짜 미정 · 못 올라감(빨강)` — 고르면 그 구역만
- 구역: 못 올라감(빨강) → 예약일 지정(예약일순) → 날짜 미정(받은 날순). 빈 구역은 안 그린다
- 줄 단추: [지금 올리기] — 예약일이 오늘보다 뒤면 확인창 「예약일 m/d 전입니다. 지금 주문탭으로 올릴까요?」 → `잠금풀기`.
  받는 분이 비었으면 올리지 않고 **주소 입력 판**(20d `판`)을 연다. [주소 입력]은 못 올라감 줄 + 원본 없는 줄에만(원본 줄은 읽기 전용이라)
- 날짜 미정: `<input type=date min=오늘>` + [날짜 저장] → `20a 고치기(id, 줄 전체+예약일)` (부분만 넘기면 사람칸이 지워진다)
- PC 머리 오른쪽 「전체 n건 · 오늘 자동으로 올라감 n건」
- 주문 카드·PC 줄의 마켓 꼬리표 옆에 「📅 예약에서 옴」 칩

## 5. 시안과 다른 점

- 하단 메뉴·사이드바 「예약」 없음(우람님 결정) → 상태 하위탭
- 시안 ③ 주문탭의 `오늘 · 📅 예약에서 옴 · 전체` 거르개 칩은 **안 만든다** — 그 자리는 이미 상태 하위탭이다. 줄마다 붙는 칩만
- 문자주문 탭 예약 갈래의 🖨 예약 출력·예약 달력 점은 갈래와 함께 빠진다
