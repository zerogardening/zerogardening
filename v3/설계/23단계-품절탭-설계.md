## 3. `06l-품절자료.js` — 읽기·파생

### 3-1. 읽기
```js
클.from('v3_지시').select('id,내용,삭제됨')
  .eq('삭제됨', false).in('내용->>갈래', ['마켓품절','마켓판매'])
  .gte('id', String(Date.now() - 30*864e5))        // id 앞 13자리 = 보낸때 ms (문자열 비교 = 시간 비교)
  .order('id', { ascending: false }).limit(300)
```
- `제때()`(10초 끊기)로 감싼다. 서버 꺼짐·표 없음 → `{오류: 말썽(e)}`(19와 같은 글).
- **품목별 카드 = 품목코드마다 가장 최근 줄 하나.** 같은 품목을 다시 보내면(실패→재시도, 품절→다시판매) 앞 줄은 안 보인다.
- 폴링: `시작()`에서 곧바로 + **15초마다**, `document.hidden`이면 건너뛴다. 읽을 때마다 결과 서명(`id+상태+JSON(마켓)` 이어붙인 것)이 바뀌었을 때만 `배지칠하기()` + (품절 탭이 열려 있으면) `ZG.품절.다시()`.
- `새로()` — 06k가 줄을 쌓은 직후 부른다.

### 3-2. 마켓 한 칸 상태 (`칸상태(줄, 마켓)` → `'ok'|'fail'|'none'|'run'|'wait'|'unk'`)
| 조건 (위에서부터) | 값 | 화면 글 |
|---|---|---|
| `내용.마켓[m]` 있음 | 완료→`ok` · 실패→`fail` · 없음→`none` | 완료 / 실패 / 없음 |
| 지시 `상태` = `대기` | `wait` | 대기 |
| 지시 `상태` = `하는중` | `run` | 진행중 |
| 지시 `상태` = `실패`·`거부` | `fail` (사유 = `답장` 첫 줄) | 실패 |
| 그 밖(`됨`인데 칸 없음) | `unk` | 기록 없음 |

- 「진행중」 근거 = **지시 줄 `상태 === '하는중'`**(맥이 집었다). 맥이 꺼지면 거기 멈춰 있다 — 그대로 진행중으로 보인다(정직하다).
- 🔴 시안 구절초(심폴 완료·스스 진행중·나머지 대기)처럼 **한 마켓씩 차오르는 모습은 못 낸다** — 맥이 끝날 때 한 번에 적는다. 하는중이면 맥 몫 여섯이 함께 `run`.

### 3-3. 카드 (`카드들()` → 배열)
```js
{ 품목코드, id, 갈래, 다시판매: 갈래==='마켓판매', 보낸때, 이름, 학명,
  칸: [{마켓, 값, 사유, 때}] ×7,  완료수, 분모, 무리: '실패'|'진행중'|'완료', 옛줄: !내용.마켓, 답장 }
```
- `이름` = 품목표(`ZG.저장소.읽기(키.품목)`)의 `유통명` → 없으면 `내용.폴더` → 품목코드. `학명`은 PC 검색용.
- `완료수` = `ok` 개수 · `분모` = 7 − `none` 개수(없는 마켓은 셈에서 뺀다. 7곳 다 있으면 시안대로 `/7`).
- `무리`: `fail` 하나라도 → **실패** · 아니고 지시 `대기|하는중` → **진행중** · 아니면 **완료**(`unk`가 섞여도 완료 — 맥이 「됨」이라 했다).
- 정렬: 실패(최근 위) → 진행중(**먼저 보낸 것 위** = 맥이 집는 순서) → 완료(최근 위).

### 3-4. 옛 줄(`내용.마켓` 없음 — 지금 30줄 전부)
7칸 다 `unk`가 아니라 위 표대로(대기·하는중·실패는 그대로, 됨이면 `unk`). 분수 자리에 `기록 없음`(회색 작은 글). 펼치면 마켓 표 대신 `답장`을 `.why`(실패면 빨강, 됨이면 회색)로 줄바꿈 그대로 보인다.

### 3-5. 배지 (`배지칠하기()`)
`[data-품절배지]` 를 모두 찾아 — 실패 카드 >0 → `빨강` + 실패 수 · 아니고 진행중 >0 → 회색 + 진행중 수 · 아니면 `hidden`. 칠한 뒤 `ZG.앱.알약맞추기 && ZG.앱.알약맞추기()`(PC 알약 너비가 바뀐다). 못 읽었으면 숨긴다(숫자를 지어내지 않는다).
> 시안 배지 「3」·실패칩 「1」은 그림용 숫자가 안 맞은 것 — **배지 = 실패 카드 수**(지시대로).

내보내기: `ZG.품절자료 = { 시작, 새로, 카드들, 상태: ()=>({오류, 읽음}), 배지칠하기, 마켓들 }`.
