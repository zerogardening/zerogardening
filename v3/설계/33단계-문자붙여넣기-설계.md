## 값·규칙 (한 곳 = 20h `나누기`)
1. 전화 먼저 뽑는다(휴대폰·지역번호, 띄어쓰기·점·하이픈 상관없음)
2. 이름표(성함·이름·받는 분·수령인·주소·연락처·전화·핸드폰…) 지움
3. 줄·「/」로 끊고, 시·도 이름이 든 덩어리 → 그 자리부터 주소, 앞 2~4글자 한글 = 이름. 시·도가 없으면 ○○시·군·구·읍·면·동·리·로·길이 든 덩어리 전체
4. 주소 다음 덩어리가 동·호·층·아파트·빌라…면 주소 뒤에 잇는다
5. 남은 2~4글자 한글 = 이름(님·입니다 떼고 인사 빼고)
6. 08c 도로식(도로명+번호)까지 = 주소칸, 뒤 = 상세. 아니면 지번(동·리·가+번지)까지. 둘 다 아니면 통째 주소칸
7. 칸 넣기: 이름·전화가 비었으면 넣고, **이미 다르게 적혀 있으면 확인창 「적힌 것과 다릅니다」**(그대로 두기 / 붙여넣은 걸로 · 질문 3 답). 주소·상세는 넣고 우편은 비움. `원문주소` = 붙여넣은 주소 통째
8. 넣자마자 주소 찾기를 연다(검색어 = 주소칸). 고르면 19단계 `주소비교` 그대로. **고르지 않고 닫으면** 빨간 줄 「✕ 주소 검색에서 못 골랐습니다 — 안 뜨면 직접 입력해 주세요」 + 미확인 칩
9. 확인줄(✓·!)에 「원문」(붙여넣은 통째)·「검색」(고른 도로명 주소)·「지번」
10. 무료배송: 누르면 `배송비 0`·`무료배송 true`(단추 초록) · 다시 누르면 4,500 · 배송비를 치면 풀림 · 저장 때 배송비가 0일 때만 true. 문자: 배송비 줄 자리(품목 아래·합계 위)에 「무료배송」(질문 4)
11. 견적 문자: 입금계좌 바로 아래 「구매자 성함으로 입금해 주세요」(입금 확인이 구매자명=입금자명 · 계좌가 있을 때만) · 끝줄 「📌 성함, 주소를 보내주세요!」(전화 요청 뺌)
