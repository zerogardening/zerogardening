## 3. `js/17-메모.js` — 자료 + 목록 + 편집기 + 달력 + 사진

### 3-1. 자료 (화면 없음)

```js
function 오늘()            // '2026-08-18'
function 새id(종류, 날짜)  // 메모 'm-'+Date.now().toString(36)+'-'+난수4 · 일지 '일지-'+날짜
function 목록(조건)        // 조건 { 종류, 달:'2026-08'|'', 검색:'', 폴더:'', 상태:'' } → 날짜 내림차순
function 날짜묶기(줄들)    // [{ 날짜, 줄들:[…] }] — 목록 머리글용
function 한장(id)
function 저장(값)          // id 있으면 저.바꾸기, 없으면 저.덧붙이기. 고친때 갱신. 저장한 레코드를 돌려준다
function 지우기(id)
function 폴더세기(달)      // [{ 이름, 수 }] — 쓰인 폴더만. 칩 줄과 <datalist> 가 같이 쓴다
function 상태세기(달)      // { 할일:n, 하는중:n, 끝:n }
function 일지날들(년월)    // { '2026-08-02': true, … } — 달력 점
function 제목뽑기(본문HTML)// 첫 줄 텍스트 60자. 비면 '(제목 없음)'
function 미리보기(본문HTML)// 태그를 걷어낸 평문 (카드 2줄용)
```

- 🔴 **캐시를 두지 않는다.** 한 달치 수십 줄이라 그릴 때마다 돌아도 싸고, 캐시를 두면 남이 고친 뒤 옛 값이 남는다
- 🔴 `제목뽑기`·`미리보기`는 **`innerHTML`로 만든 임시 `<div>`의 `textContent`**로 뽑는다. 카드에 HTML을 그대로 꽂지 않는다
- `저장(값)`은 **본문 평문이 비어 있으면 아무것도 안 하고 `null`을 돌려준다**(확정 설계 §4)

### 3-2. 편집기 — `execCommand`를 한 함수에 가둔다

```js
/* ponytail: execCommand 는 폐기예정이다. 갈아탈 때는 이 함수 하나만 고친다 —
   Selection API + Range 로 <span> 을 직접 씌우고, 되돌리기는 자체 스택을 든다.
   부르는 자리를 늘리지 마라. 늘어나면 갈아탈 수 없다. */
function 서식(무엇, 값) {
  // 무엇: 'bold' | 'size' | 'color' | 'mark' | 'unmark'
}
function 편집기만들기(초기HTML, 바뀜)   // { 뿌리, 읽기(), 쓰기(html), 사진넣기(파일) } 를 돌려준다
```

- 켤 때 한 번 `document.execCommand('styleWithCSS', false, true)` — `<font>` 태그 대신 `style`로 남아 저장이 깔끔하다
- `size` 는 3단계 순환 — `execCommand('fontSize', false, '3'|'5'|'6')`
- `color` 는 `foreColor`. 팔레트 **검정·빨강·초록·파랑·회색**
- 🔴 `mark` 는 **`hiliteColor`를 먼저 시도하고 `false`가 돌아오면 `backColor`로 떨어진다** — 웹킷이 `hiliteColor`를 안 받는 판이 있다. 팔레트 **노랑·연두·하늘·분홍**, `unmark`는 `transparent`
- 🔴 도구줄 단추 전부에 `mousedown` → `preventDefault()`. 안 걸면 누르는 순간 선택이 풀린다
- 🔴 붙여넣기 가로채기 —
  ```js
  뿌리.addEventListener('paste', function (e) {
    e.preventDefault();
    var t = (e.clipboardData || window.clipboardData).getData('text/plain');
    document.execCommand('insertText', false, t);
  });
  ```
- 자동저장 — `input` 이벤트에서 3초 디바운스 + `blur`. 🔴 큐는 `'표|id'`로 합쳐지므로(`01c:8`) 몇 번을 저장해도 서버로는 한 줄만 간다

## 7. Supabase — 🔴 우람님이 **먼저** 돌리셔야 push한다

표가 없는 채로 올리면 `표받기('메모')` 404가 `Promise.all`을 흔들어 다른 표까지 늦어진다(방패는 `01b:207`에 있지만 경고가 뜬다).

```sql
-- ① 표 v3_메모 (7단계 설계 §1 규격과 같다. v3_손댐() 은 이미 있다)
create table if not exists public.v3_메모 (
    id text primary key,
    내용 jsonb not null,
    삭제됨 boolean not null default false,
    수정시각 timestamptz not null default now(),
    수정자 uuid default auth.uid());

drop trigger if exists 손댐 on public.v3_메모;
create trigger 손댐 before update on public.v3_메모
    for each row execute function public.v3_손댐();

create index if not exists v3_메모_시각 on public.v3_메모 (수정시각);

alter table public.v3_메모 enable row level security;
drop policy if exists "로그인한사람만" on public.v3_메모;
create policy "로그인한사람만" on public.v3_메모
    for all to authenticated using (true) with check (true);

do $$ begin
  alter publication supabase_realtime add table public.v3_메모;
exception when duplicate_object then null; end $$;
```

```sql
-- ② Storage 버킷 — 🔴 이름은 'memo' 다. 한글 버킷은 만들어지지 않는다 (설계 §0-3)
insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
values ('memo', 'memo', false, 10485760, array['image/jpeg','image/png','image/webp'])
on conflict (id) do nothing;

-- ③ 버킷 정책 — 표와 같은 규칙(로그인한 사람만). 익명은 전부 막힌다
drop policy if exists "메모사진_읽기"   on storage.objects;
drop policy if exists "메모사진_올리기" on storage.objects;
drop policy if exists "메모사진_지우기" on storage.objects;
create policy "메모사진_읽기"   on storage.objects for select to authenticated using (bucket_id = 'memo');
create policy "메모사진_올리기" on storage.objects for insert to authenticated with check (bucket_id = 'memo');
create policy "메모사진_지우기" on storage.objects for delete to authenticated using (bucket_id = 'memo');
```

**확인하는 법** — SQL Editor에서 `select count(*) from public.v3_메모;` 가 `0`을 돌려주고,
Storage 화면에 **`memo`** 버킷이 보이면 된다.
