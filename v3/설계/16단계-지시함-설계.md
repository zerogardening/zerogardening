## 🔴 두 라인을 하나로 합쳤다

우람님은 둘로 그리셨다 — ①어떤 액션을 하면 자동 착수 ②앱에 채팅처럼 지시를 쌓는다.
**①은 「시스템이 대신 채팅을 치는 것」으로 두면 ②에 흡수된다.**

```
사진 11장이 다 찼다  →  시스템이 지시함에 한 줄 넣는다
우람님이 손으로 치신다 →  같은 표에 한 줄
                          ↓  맥 입장에선 똑같다
```

만들 물건이 절반이 된다. 자동 트리거(⑥)를 나중에 얹어도 앞이 안 바뀐다.

## 🔴 결정 넷 — 왜 이렇게 했나

### ① 위험한 일은 글로 거르지 않는다. 연장을 안 준다

`--allowedTools` 에 **Bash 가 없다.** 그래서 지우기·`push`·결제가 **애초에 불가능하다.**
글로 거르면(「지워」 같은 말을 막으면) 우회당한다. 연장이 없으면 우회할 것이 없다.

2026-09-14 시험 — 파일 쓰기 ⭕ / `rm` 으로 지우기 ❌ (실제로 못 지웠다)

### ② 커밋·push 는 Claude 가 아니라 스크립트가 한다

무엇이 올라가는지 한 곳에서 다 보인다. 그리고 **Claude 가 만진 파일만** 올린다 —
돌리기 전후의 `git status` 를 견줘 고른다. **`git add -A` 를 안 쓴다**(다른 창 작업이 딸려 나간 적이 있다).

🔴 **`git status --porcelain -z` 를 반드시 쓴다.** `-z` 없이는 한글 파일명을
`"\354\213\234…"` 로 감싸 escape 해서 주고, 그대로 `git add` 에 넘기면 조용히 실패한다.
이 집은 파일 이름이 죄다 한글이라 이것 하나로 커밋이 통째로 안 된다. **통합시험에서 잡았다.**

### ③ 우람님이 쓰고 계시면 집지 않는다

`ioreg` 의 `HIDIdleTime` 으로 마지막 입력 뒤 시간을 잰다. 60초 안이면 그 바퀴는 건너뛴다.
**돌던 것은 끝까지 간다** — 중간에 죽이면 파일이 반쯤 고쳐진 채 남아 더 위험하다.

### ④ 결과물은 자동 push, 프로그램 코드는 커밋까지

| | |
|---|---|
| `제로가드닝/`(ops · 비공개) — 원고·이미지·블로그 글 | 자동 push. 웹에 안 뜬다 |
| `통합관리/`(공개 · GitHub Pages) | **커밋까지만.** push 하면 1~2분 뒤 실서비스 화면이 바뀐다 |

지시함이 도는 창은 `제로가드닝/` 하나다. 통합관리는 애초에 다른 저장소라 섞이지 않는다.

3. **상품팀 워크플로우와 얽힌다.** 어느 창에서 부를지(허브냐 상품 창이냐),
   서브에이전트를 쓸지가 정해져야 한다.

## 얹을 때의 모양

시스템 줄에 `갈래` 를 둔다. **표의 `글` 을 프롬프트로 쓰지 않는다** —
`갈래` 가 아는 값일 때만 **박아 둔 프롬프트**를 쓴다. 표가 오염돼도 정해진 일만 한다.

```
{누가:'시스템', 갈래:'상세페이지', 품목코드:'…', 글:'(사람이 읽을 말)'}
```

- `누가==='시스템'` 이고 `갈래` 를 알 때만 Bash 를 연다
- 그때도 `Bash(python3:*)`·`Bash(sips:*)` 처럼 좁혀 준다
- 🔴 **진열은 켜지 않는다.** `uploader` 가 원래 안 켠다 — 마지막 관문은 우람님이다
