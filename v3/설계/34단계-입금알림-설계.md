## 결론 — 서버와 매칭은 하나, 받아 오는 입구만 폰마다 다르다
아이폰과 갤럭시에서 **완전히 같은 방법은 안 된다**(아래 사실). 그래서:

| 층 | 하나로 같음 | 폰마다 다름 |
|---|---|---|
| ① 받는 곳 | Edge `deposit-in` 하나 · 몸 `{text, 입구, 보낸곳}` · `?k=` 가게 열쇠 | — |
| ② 은행별 읽기 규칙 | Edge 안 `규칙` 표(지금 농협 하나 · 새 은행은 글 1통 보고 한 줄) | — |
| ③ 매칭·자동 올리기 | 구매자명 = 입금자명 + 금액 (2단계) | — |
| ④ 수집기(입구) | — | 아이폰 = 단축어 「메시지」 자동화(**문자만**) · 갤럭시 = 도우미 앱 알림 읽기(**문자 알림·은행 앱 알림 둘 다**) |
| ⑤ 처음 설정 | 「어느 은행」을 고르면 발신번호·앱을 우리가 채워 줌 | 아이폰은 단축어에서 보낸 사람(연락처) 고르기 · 갤럭시는 앱 안에서 「받을 앱」 체크 |

## 사실 (출처는 보고서)
- 아이폰: 다른 앱의 알림·문자를 읽는 공개 방법 없음. 알림 API는 자기 앱 알림만. 단축어 자동화는 「메시지」(문자)엔 걸리고 **앱 알림엔 걸리는 트리거가 없다** → 은행 앱 푸시는 아이폰에서 못 받는다. 농협 문자(유료 SMS 통지)가 있어야 한다
- 아이폰 메시지 필터 확장(ILMessageFilterExtension): **연락처에 없는 발신자의 문자만** 보고, 본문을 서버로 넘기는 길(deferQueryRequestToNetwork)은 **스팸 거르기용**. 입금 수집에 쓰면 ⓐ 「농협」을 연락처에서 지워야 하고 ⓑ 설정 › 메시지에서 필터 앱으로 켜야 하며(한 개만) ⓒ 목적 밖 사용이라 심사 탈락 위험 → **쓰지 않는다**
- 갤럭시: `NotificationListenerService` 로 모든 앱 알림(삼성 메시지 문자 알림 · 농협 앱 푸시) 글을 받는다 · 사용자가 설정 › 알림 접근에서 직접 허용 · Play 심사는 별도 신고서 없음, 대신 「개인정보 눈에 띄는 고지 + 동의」 화면·개인정보처리방침·데이터 보안 칸 필수 · Android 15부터 **인증번호(OTP) 알림은 가려짐**(입금 알림은 해당 없음)
- 문자 읽기 권한(READ_SMS)은 기본 문자앱이거나 「SMS 가계부」 예외 신고 · 심사 → 쓰지 않는다(알림 읽기로 충분)
- v3는 웹앱이라 **어느 폰에서도** 알림·문자를 못 읽는다 → v3에 붙이는 입구는 아이폰 = 단축어, 갤럭시 = 작은 도우미 앱(APK 직접 설치 · 플레이 안 거침 · 나중 문자앱의 안드로이드 수집기를 먼저 떼어 만든 것)

## 처음 설정 — 고르게 해야 하나 → **예(은행만 고르면 나머지는 우리가 채움)**
- 왜: 아무 알림이나 다 보내면 개인 문자·카톡까지 서버로 간다(개인정보 · Play 고지 위반) · 규칙도 은행별이라 은행을 알아야 읽는다
- 아이폰: 「보낸 사람」을 단축어가 연락처로만 고르게 한다 → 은행 발신번호(농협 1588-2100)를 연락처에 저장 → 고르기. 문자앱에선 단축어 공유 링크 + 「은행 고르기」 화면이 번호를 알려 줌
- 갤럭시: 도우미가 깔린 앱 목록에서 은행 앱·메시지 앱을 체크(기본은 고른 은행 앱 + 메시지 앱의 그 은행 발신번호만) · 체크 안 한 앱 글은 폰 밖으로 안 나감
- 문자·앱 알림 둘 다 켜져 같은 입금이 두 번 와도 id(시각·금액·이름)가 같아 한 줄

## 1단계 — 지금 (우람님 아이폰 · 단축어)
| 파일 | 새/고침 | 줄 |
|---|---|---|
| `도구/edge-입금알림/index.ts` (슬러그 `deposit-in`) | 새 | 54 |
| `v3/검수/46-입금알림/입금알림-시험.py` | 새 | 30 |
| 앱(v3 js·html) · SQL | 안 고침 · 없음 | 0 |
- 저장: `v3_공유설정` id `입금:2026-11-10T09:29:30000:홍길동` · 내용 `{은행, 이름, 금액, 시각, 입구, 받은시각}` · 🔴 잔액·계좌번호·원문 버림 · 30일 지난 줄은 받을 때 지움(cron 없음)
- 앱 01b는 설정행이 아닌 공유설정 줄을 받기만 하고 넘김(225·279행) → 앱 영향 없음
- 열쇠: `verify_jwt:false` + `?k=` = 비밀값 `DEPOSIT_TOKEN`(없으면 전부 거절) · `{"시험":true}`는 읽기만
- 규칙 표(농협): 금액 `입금\s*([\d,]+)\s*원` · `MM/DD HH:MM <계좌> <이름> 잔액…`(이름 = 계좌 다음 ~ 「잔액」 또는 줄 끝 · 띄어쓰기 든 회사명 그대로) · 「출금」 있으면 버림 · 문자 달 > 지금 달이면 작년

### 시험 예시 (`검수/46-입금알림` 7/7)
| 글 | 기대 |
|---|---|
| `[Web발신]\n농협 입금30,000원\n11/10 09:29 351-****-0000-00 홍길동 잔액1,000,000원`(우람님 캡처) | 농협 · 홍길동 · 30000 · 2026-11-10T09:29+09:00 |
| `농협11/10 05:56 … 자동출금\n900원(UMS수수료)…` | 버림 |
| 한 줄 1,234,000원 · 「주식회사 초록」 · 잔액 없음 · 1월에 받은 12/31 · 「입금 이벤트」 광고 | 1234000 · 주식회사 초록 · 박영희 · 2025-12-31 · 버림 |

### 서버 부담
- 수집기 부름: 입금 1건 = 1번 · 약 0.2KB · 하루 20건(주문 외 입금 넉넉히) = 0.004MB
- 공유설정을 통째로 받는 화면(index·주문·소싱·업체)에 입금 줄이 딸려 감: 30일×20건 = 600줄×0.2KB = 한 번 열 때 최대 0.12MB(압축 약 0.03MB) · 하루 50번 열면 약 1.5MB — 기준 50MB의 3% · 2단계에서 `v3_입금` 표로 옮겨 주문 화면만 받게 할 수 있음

## 2단계 — 1주 시험 뒤 (설계만)
### 가. 매칭 (같은 규칙을 문자앱도 씀)
- 대상: 입금 표시 없는 최근 7일 문자주문(예약 포함) · **구매자명(받는분) = 입금자명**(입금자 칸 없음 · 견적 문자에 「구매자 성함으로 입금해 주세요」)
- 이름 비교: 띄어쓰기·(주)·주식회사·숫자 빼고 · 앞부분 같으면 같음(잘려 옴)
- 초록(자동): 이름·금액(`합계().합`) 딱 맞는 1건 · 주황: 이름 같고 금액 다름 · 같은 이름 2건 이상: 금액 맞는 1건만 초록, 아니면 「골라 주세요」(두 건 합 = 입금액이면 제안만) · 회색: 입금 전(하루 지나면 빨간빛) · 노랑: 이름 안 맞고 금액 같은 1건 → 눌러 확정 · 아무것도 없으면 「주인 모를 입금」
- 🔴 짝은 **입금 줄에** 적는다(`짝: 문자주문 id`) — 문자주문 줄은 앱이 통째로 덮어써서 서버가 거기 쓰면 지워질 수 있다 · 한 입금은 한 주문에만
### 나. 카드 색 띠 (`20c` 폰카드·PC줄 · 매칭 함수는 `20a` 한 곳)
- 카드 맨 위 가장자리 한 줄(올림·예약 칩과 안 겹침) · 초록 「입금 ✓ 11/10 09:29 · 30,000원」 · 주황 「금액 다름 · 30,000원 들어옴(6,000원 모자람)」 · 회색 「입금 전」 · 노랑 「이분 입금일까요?」 · 누르면 입금 이름·금액·시각, 잘못 붙은 것 떼기
### 다. 주문완료 문자 → 입금 기다림 → 자동 올리기 (문자앱 방식을 v3에서 먼저)
- 단축어·알림 읽기는 **받은** 글만 본다 → 주문완료 문자는 **앱 단추**로 보낸다(지금 견적 문자처럼)
- 단추 = 붙여넣기(33단계)로 들어간 이름·전화·주소로 문자주문 줄 「입금 기다림」 + 문자앱 열기
- 그 줄이 초록이 되면 20d `주문올리기` · 🔴 첫 주는 「올릴까요?」 한 번 누르기(우람님 답 기다림) · 주황·노랑은 자동 안 올림
- v3에선 앱이 열려 있을 때 올림(서버에 주문올리기 사본을 두지 않음 · 같은 코드 두 번 금지). 폰이 꺼져 있어도 올려야 하면 그때 올리기를 서버로 옮김 — 문자앱은 처음부터 서버 쪽
### 라. 갤럭시 도우미 (v3용 · 쓸 사람 생기면)
- 화면 하나: 은행 고르기 · 받을 앱 체크 · 「개인정보 고지 + 동의」 · 열쇠 넣기 → 알림 오면 체크한 앱 글만 `deposit-in` 으로(`입구:"안드로이드알림"`) · 농협 앱 푸시 글 모양은 실물 1통 받아 규칙 한 줄 추가
