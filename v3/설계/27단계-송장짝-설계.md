# 27단계 — 문자주문 송장 확실히 붙이기 (10/20)

배경: 10/17(금) 문자주문 2건(김형하·성미연)이 로젠으로 나갔는데 v3 배송완료에 안 붙어 월요일에 또 출력됐다.
새 표·SQL 없음. 저장소 규약·화면 규칙은 「1단계 설계 §10 그대로」.

## ⓐ 저장 실패 · 못 올라간 기록 — 맨 위 빨간 띠
- `01-저장소 저장()` localStorage 실패를 키별로 기억(`저장실패()` 건수) — 같은 키가 다음에 써지면 풀린다(표를 통째로 쓰므로 그때 다 들어간다)
- `01c 큐저장()` 실패도 같은 띠에 「이 기기에 저장 실패」
- `01c 표시()` 띠 = body 맨 앞 보통 블록(폰 머리·PC 옆판이 top:0이라 고정하면 가린다) · `#D70015` 흰 글씨
  - 글: `⚠ 이 기기에 저장 실패` · `⚠ 서버에 못 올라간 기록 n건`(1분 넘은 큐만) — 해당 없으면 띠가 없다
  - 누르면 그 자리서 다시 보낸다 · 15초마다 다시 센다
  - 새로고침하면 크롬이 스크롤을 「보던 줄」 기준으로 되살려 띠 높이만큼 내려간다 → `pageshow`에서 띠 높이 이내면 맨 위로
- 01c를 싣는 html 전부 `01-저장소.js`·`01c-보내기.js ?v=140`

## ⓑ 로젠 S열(주문번호) 빈 줄 — 이름+전화 자동 짝
- `08f 읽기시트` J(9)·K(10) → `전화앞`: `*` 앞 숫자만, **5자리 미만은 버림**(`*******`·`010-****-****`는 사실상 이름뿐)
- `08f 전화후보(수하인, 전화앞들, 색인)` = 이름 완전일치 묶음(`이름묶음`, 이미 나간 건 빠짐) 중 `수령인전화` 숫자가 그 앞부분으로 시작하는 것
- `08g 판정하기` 빈번호 줄: 전화후보가 **딱 하나면 자동 연결**(「이름·전화로 찾음 · 」) · 여럿·없으면 지금처럼 「확인 필요」
- `08g 이름처리`: 전화후보가 있으면 그것만 고르기에 띄운다 · 없으면 지금처럼 이름후보
- 🔴 **이름만으로는 자동 연결하지 않는다** · 자동 연결 줄도 창 안 「되돌리기」로 확인 필요로 돌아간다
