# 28단계 — 심폴 발송 고침 (2026-10-20)

심폴 발송은 `심폴-주문배송-설계.md` §4 그대로다 — L1·L2·L3 이중발송 막이, `모드` 열쇠, 50건 묶음. **다른 것만 적는다.**

## 1. 원인 — 모든 심폴 주문이 「이미 송장 있음」으로 막혔다

심폴 CSV(`order_excel.php`)는 칸을 엑셀 수식 껍데기로 준다 — 송장 `="45392501453"`, 안 보낸 주문 `=""`.
`edge-심폴발송` `송장칸보기()`가 이 칸을 그대로 「비었나」로 봐서 `=""`도 송장이 있는 것으로 판정했다.
수집(`edge-심폴수집` `껍데기벗기기`)은 이미 벗기고 있었다.

## 2. 고친 것

| 어디 | 무엇 |
|---|---|
| `도구/edge-심폴발송/index.ts` | `껍데기벗기기` — 수집과 같은 규칙(`="…"` → 안쪽) + 파서가 따옴표를 먹은 `=…` 꼴도 벗긴다. 거래번호·송장·처리여부 세 칸 모두 벗긴 뒤 판정 |
| 〃 | CSV 판정을 `송장칸판정(csv)` 순수 함수로 떼었다(심폴 접속 없이 시험). `송장칸보기`는 받아서 넘기기만 |
| `js/08l` | `심폴발송(대상, 진행)` — `모드:'발송'`이 나가는 **유일한 자리**. 결과를 짝에 붙이고 성공만 되쓴다. `심폴결과글`도 08m에서 여기로 옮겼다 |
| `js/08m` | 위 둘을 가져다 쓴다(동작 같음) |
| `js/08g` | 체크 둘: 「카페24 송장 올리기」·「심폴 발송처리」 — 따로 켜고 끈다. 둘 다 꺼지면 [저장]=닫기 |
| 〃 폰 | 08m 없이 확인창 하나 → 카페24 먼저, 끝나면 심폴. 심폴이 끼면 제목 「…심폴 n건 발송」, 본문 「🔴 손님에게 문자가 나가며 되돌릴 수 없습니다」, 빨간 단추. 실패는 08m과 같은 글(`심폴결과글`)로 줄마다 |
| `css/주문.css` | 폰 발 줄 `.r1` 줄바꿈 허용 — 체크 둘이 안 들어가면 아래 줄로 |

L1(이미 나감·같은 거래번호 잠금)은 그대로 — 폰도 `켬`이 꺼진 줄은 안 보낸다.
08v(보류 목록 넘기기)는 여전히 심폴을 안 보낸다 — 이번 범위 밖.

## 3. 시험 — `v3/검수/28-심폴/`

- `송장칸-시험.ts` (`bun`) — 오프라인. `=""`→빈 · `="4539…"`→번호 · 평문 그대로 · 한 거래번호 여럿 중 하나라도 송장이면 막힘
- `심폴발송-시험.py` — 로컬 브라우저. supabase 주소 차단 + 서버 클라이언트를 브라우저 안 가짜로 바꿔 끼운다. 실서버·심폴 안 부름
