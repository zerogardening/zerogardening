## 0. 시안대로 — 예약 줄은 오늘 갈래에도 보인다 (팀장 확정)

예약 줄은 받은 날(`r.날짜`)의 「오늘」 갈래 목록·숫자·달력 점에 **칩을 단 채 그대로 보인다**(시안 ①ⓑ·PC① 「오늘 4」). 예약 갈래 칩에서만 두 구역으로 모아 본다.
판정은 `20a 오늘에보이나(r)` 한 곳 — `return true`. ②(주문탭→예약)는 이 문제와 상관없다.

## 1. 데이터 — `v3_문자주문.내용`에 더하는 칸

| 칸 | 값 | 언제 |
|---|---|---|
| `예약` | `true` · 없음 | 없으면 예약 아님 — **기존 줄은 손대지 않는다** |
| `예약일` | `'YYYY-MM-DD'` · `''`(날짜 미정) | `예약:true`일 때만 뜻이 있다 |
| `원본줄들` | `v3_주문` 줄 배열(통째 깊은 복사) | ② 주문탭에서 옮긴 줄만. 되살리면 `null` |
| `옮겨온일시` | ms | ② 옮긴 줄 — 「↩ 주문탭에서 옴」 표시 기준. 되살린 뒤에도 남긴다(이력) |

- **예약중(r)** = `r.예약 === true && r.상태 !== '올림'`. 올리면 `예약` 칸은 남지만 예약 리스트에서 빠지고 받은 날(`r.날짜`)의 오늘 갈래로 돌아간다.
- 원본줄들을 한 줄 안 JSON 으로 두는 이유 — 한 **건**이 통째로 오가고, 보관 중엔 아무도 줄 단위로 고치지 않는다(§4 읽기 전용). 「한 덩어리 저장」 금지와 같은 문제가 아니다: 건 하나 = 행 하나다.
- 🔴 **`r.날짜`는 그대로 받은 날이다.** 예약일은 `날짜`를 바꾸지 않는다(16단계 §2 「고치지 않는다」).

## 3. ① 예약 지정 · 리스트 · 올리기 잠금 (문자주문만)

### 3-1 판정 (`20a`)
- `올릴수있나(r)` → `{된다:true}` 또는 `{된다:false, 까닭:'예약일(10/20) 전이라 올릴 수 없습니다'}`. **예약일이 있고 `> u.오늘문자()`일 때만 막는다.** 날짜 미정·오늘·지난 날은 된다. 문자열 비교(`YYYY-MM-DD`).
- `주문올리기(id, 사람)` 맨 앞(상태 검사 다음)에 `올릴수있나` — 화면이 단추를 잠가도 여기서 한 번 더 막는다(두 기기 틈).
- `오늘에보이나(r)` = `true` (§0 — 시안대로. 빼려면 `!예약중(r)` 한 줄).
  - `거르기(날짜, 검색)` — **검색어 없을 때만** `오늘에보이나`로 거른다. 검색은 지금처럼 모든 날짜·모든 줄(예약 포함, 칩으로 가린다).
  - `점표(달)` — `오늘에보이나` 줄만 점. 요약(`20c 요약`)은 `거르기`를 쓰므로 저절로 따라온다.
  - `오늘보낸수()` — **안 바꾼다.** 새 문자 화면의 「오늘 문자 N건」은 보낸 문자 수라 예약 여부와 무관하다.
- `다듬기(값)` — `'예약' in 값`일 때만 `예약: !!값.예약, 예약일: 값.예약 ? (값.예약일 || '') : ''`를 더한다. 20b 새로저장은 `예약` 키를 안 넘기므로 새 줄은 예약 아님 그대로.

### 3-2 예약 자료 (`20e`)
- `예약목록()` → `{ 지정: [...], 미정: [...] }` — `전부().filter(예약중)`. **날짜로 거르지 않는다.**
  - 지정 = `예약일` 있음 · `예약일` 빠른 순 → `등록일시` 순. 머리줄은 예약일마다.
  - 미정 = `예약일` 빔 · `r.날짜`(받은 날) **오래된 날 위** → `등록일시` 순. 머리줄은 받은 날마다.
- `D글(날)` — 오늘과의 날수 `n`: `0 → '오늘'` · `n>0 → 'D-n'` · `n<0 → 'D+|n|'`. **때됨** = `예약일 <= 오늘`(주황 `.due`/`.때됨`).
- `지난글(날)` — 받은 날 머리줄 꼬리: `오늘` · `어제` · `n일 전`.
- `예약점표(달)` — 그 달 **예약일** 표(PC 예약 갈래 달력의 주황 점 `i.rv`).
- 날수 셈은 `new Date(y, m-1, d)` 끼리 빼서 `/86400000` 반올림(서머타임 없음).

### 3-3 화면 (`20c`·`20f`)
- **상태** `상태.갈래 = '오늘' | '예약'` · `상태.방금 = {}`(② 강조). `목록으로()`는 `'오늘'`로 되돌린다. `날짜고르기()`·달력 날 누르기는 **언제나 `'오늘'`로** 간다.
- **갈래 칩줄** `.fchips` — `[오늘 n]` `[예약 n ●]`. n = 고른 날 건수(헤더와 같은 수) / `예약목록` 합. `●`(`.점`) = 때된 예약이 하나라도 있으면. 예약 칩 켜짐은 `.fchip.on.예약`(보라).
  자리: 폰 = `머리줄`(새 문자·검색) 바로 밑 · PC = 왼쪽 `.cl` 안 달력 **위**.
- **오늘 갈래** = 지금 화면 그대로.
- **예약 갈래** (검색어가 있으면 갈래와 상관없이 지금의 검색 목록)
  - 폰: 달력 **안 그린다**. `구역머리`(📅 예약일 지정 n건 · 합원) → 예약일 `예약머리`(날글 · D글 · n건 · 합원) → 카드 … `구역사이` → `구역머리.미정`(날짜 미정) → `예약머리.받은머리`(날글 받음 · 지난글) → 카드. 빈 구역은 통째로 안 그린다. 둘 다 0이면 `예약 주문이 없습니다`.
  - 폰 카드 = 지금 `폰카드` + r1 에 `예약칩(r)`·`D글`(지정만) · r2 밑에 `.품`(품목 요약 · 배송비). 때된 카드 `.때됨`.
  - PC: 달력은 그대로 두되 점은 `예약점표`. 표 머리 `예약일 · 받는 분 · 상태 · 품목 · 금액 · (단추)` — 둘째 칸이 시각 대신 `td.예약칸`(예약칩 + `.dn`), 상태칩은 이름 밑으로, 끝칸은 `💬 문자`·`주문올리기`. 구역은 `tr.구역줄`/`tr.구역줄.미정`, 날 머리는 `tr.묶음`(`.때됨`), 사이 `tr.틈2` — **시안 18b ② PC 마크업 순서 그대로.** 머리글 `예약<small>n건 · 합원</small>` · 🖨 출력은 지정+미정을 이어서.
  - 요약(폰 `.ph-sub`): `예약 <b>n</b>건` / `지정 <b>a</b> · 미정 <b>b</b>`.
- **예약칩(r)** — 지정: `.st.resv` `예약 10/20` (때됨이면 `.due`) · 미정: `.st.resv.미정` `예약 · 날짜 미정`(PC 예약칸은 `날짜 미정`). 오늘 갈래·검색 목록에서도 예약중이면 상태칩 옆에 붙인다.
- **펼친 판 예약칸** `예약칸(사본, 폰, 바뀜)` — 사람칸 밑, 품목 위(시안 ①ⓐ 자리). 라벨 `예약 <span class="auto">선택</span>`.
  - `.예약줄` = `.예약고름`[📅 예약일 정하기 | 날짜 미정] + 예약이면 `[예약 해제]`. 켜진 쪽 `.on`.
  - 정하기 → `.날짜칸` 읽기전용 칸(`10월 20일 (화)`, 정했으면 `.정함`) + `날짜판`. 칸을 누르면 판을 접었다 편다. **지난 날 `.지난`은 못 누른다**(오늘은 된다).
  - 날짜 미정 → `사본.예약=true, 예약일=''`. 해제 → `예약=false, 예약일=''`.
  - 🔴 **예약칸만 다시 그린다**(`항목칸만들기` 방식) — 사람칸을 갈면 치던 글·한글 조합이 날아간다. 판 열림·달은 `상태.열린.예약판 = {열림, 달}`에 들어 남이 저장해 다시 그려져도 남는다.
  - `바뀜()`이 `고침단추들`의 주문올리기 단추만 고친다: 잠김이면 `disabled` + `.잠김` + 글 `🔒 주문올리기`. 판정은 사본 값으로(저장 전에도 바로 잠긴다).
  - 저장은 지금 `저장` 단추 → `고치기` 한 길(§3-1 다듬기).
- **접힌 줄 🔒** — `폰카드`·`PC줄`의 `주문올리기` 단추를 `올릴수있나(r)`로 잠근다(`단추(..., 끔)`). `20d 판정()`에도 `|| !자().올릴수있나(자().하나(r.id) || r).된다`.

## 4. ② 주문탭 → 예약 「보관 이동」 · 되살림

### 4-1 대상 — `20e 넘길수있나(g)`
- **건의 모든 줄이 `출처 === '수동'`** 일 때만 된다(수동주문 + 문자 올림). 카페24·스마트스토어·심폴·당근(`업로드`·`카페24`·자동수집)은 막는다. 🔴 `g.출처`는 첫 줄 것뿐이다 — 묶음키(이름·전화·주소)가 같으면 마켓 줄과 수동 줄이 한 건에 섞인다. **줄마다 본다.**
- 배송완료 — `ZG.주문입력.나간줄(g.줄들)`(출고 `출처==='주문'`)이 하나라도 있으면 막는다. 단추는 살려 두고 **누를 때** 토스트 `⛔ 배송완료된 주문은 넘길 수 없음`(시안 ③ⓓ·PC③ⓑ). 마켓은 단추 자체를 끈다(시안 ③ⓔ·PC③ⓒ).

### 4-2 단추 자리 (`08b`)
- **PC** `PC아래줄` — `서비스` 뒤에 `btn sm 넘김` `📅 예약으로 넘기기`. 고른 건 0 · 하나라도 `넘길수있나` 거짓이면 `disabled`. 🔴 「고른 게 없으면 전체」(`고른건들()`)를 **쓰지 않는다** — 함수 첫 줄의 `고름`을 쓴다.
- **폰** `상세그리기` — 수정·삭제 `topbtns` 바로 밑, 손 배송완료 단추 위에 `btn 넘김 넘김큰`. 한 건만.
- 누르면 `ZG.예약화면.넘기기창(건들, 끝)`.

### 4-3 확인 팝업 — `20f 넘기기창` (시안 ③ⓑ·PC③ⓐ)
`04 확인()` 뼈대(askscrim · askbox · Esc 닫기 · Tab 가두기 · 열기 전 `.askbox` 있으면 안 뜸)를 그대로 따라 **20f 안에 짓는다** — `u.확인`은 본문이 html 글뿐이라 칸을 못 넣는다(04 를 고치면 모든 html 판이 올라간다).
- 건마다 `.넘김건`: `.누구`(이름 · 전화 · `.mall` = 판매처 `'문자'`면 `문자주문` 아니면 `수동주문`) · 줄마다 `.줄`(유통명 · 규격 · 수량) · `.합`(`품목 n줄` + 배송비 있으면 `· 배송비 x` / 금액). 건이 셋을 넘으면 그 칸만 넘쳐 굴린다.
- `.결과줄` `주문 목록에서 빠지고 예약 리스트로 이동` · `.예약고름`(기본 **날짜 미정**) · 정하기면 `날짜판` · `[취소] [예약으로 넘기기]`(정하기인데 날 안 골랐으면 꺼짐).
- 누르면 단추 끄고 `옮기는 중…` → `ZG.예약자료.옮기기(건들, 예약일)` → 성공이면 창 닫고 `ZG.견적탭.탭으로('문자')` **다음에** `ZG.문자주문.예약으로(새id들)`(탭으로가 `나가기()`로 뷰를 새 문자로 돌리므로 순서 지킨다. 폰은 먼저 `08b 열기('목록')`). 토스트 `📅 예약 리스트로 옮김 · 윤서진`(여럿이면 `외 n건`). 실패면 창 그대로 두고 토스트.
- `예약으로(ids)` — `뷰='목록' · 갈래='예약' · 방금=ids` 후 다시. 방금 줄은 `.옮겨옴`(보라 테두리) — 갈래를 바꾸거나 목록으로 가면 지운다.
- 배송비: 수동주문 줄에는 배송비 칸이 없다(시안 「배송비 4,500」은 그림용). 문자 올림 건이면 흡수할 문자주문의 `배송비`를 쓴다.

### 4-4 옮기기 — `20e 옮기기(건들, 예약일)` → Promise `{새id들}` | `{오류}`
**순서가 곧 안전장치다. 예약 줄을 먼저 쓰고, 확인하고, 그 뒤에 지운다.**

1. **다시 읽는다** — 건마다 `g.줄들`의 id 로 `v3_주문`을 새로 읽어 `지금줄들`(그새 지워진 줄 빼고). 0이면 그 건은 건너뜀.
2. **다시 막는다** — `넘길수있나` · `나간줄`(확인창 뒤 두 기기 틈 — 17단계와 같은 이유).
3. **흡수할 문자주문** — `지금줄들`의 `문자주문id`(빈 값 빼고)마다 `20a 하나(id)`가 `상태==='올림'`이면 흡수 대상. 그 문자주문의 `지울줄(r)` 중 `지금줄들`에 없는 줄이 있으면 **그 건 오류**(`이 문자주문의 다른 줄이 따로 있어 넘길 수 없습니다`) — 반쪽만 옮기지 않는다.
4. **이미 있나(멱등)** — `예약중` 이고 `원본줄들` id 가 `지금줄들` id 와 하나라도 겹치는 줄 `R`이 있으면 새로 안 만든다. `지금줄들` 중 R 에 없는 줄은 `R.원본줄들`에 **덧붙여** `바꾸기`(끊긴 뒤 주문탭에서 서비스가 더해진 경우). 없으면 새 줄:
   `{id:새id, 날짜: 흡수 문자주문의 날짜 || 지금줄들 주문일 중 가장 이른 날, 상태: 흡수한 것이 보낸일시 있으면 '보냄' 아니면 '저장', 보낸일시, 받는분: g.수령인, 전화: 숫자만(g.전화), 주소: g.주소, 상세주소:'', 우편: g.우편번호, 배송메시지: g.배송메모, 메모·배송비: 흡수한 것(하나일 때) 또는 ''·0, 품목: 서비스 아닌 줄 → {품목코드, 유통명, 학명, 규격, 수량: ZG.주문자료.수량(o), 단가}, 예약:true, 예약일, 원본줄들: JSON 깊은 복사, 옮겨온일시, 등록일시, 수정일시}` → `덧붙이기`.
5. **확인** — 모든 건의 R 을 쓴 **뒤 한 번에**: ⓐ 로컬 `하나(R.id).원본줄들` id ⊇ `지금줄들` id ⓑ `ZG.서버.켜짐`이면 `ZG.보내기.깨우기()` 뒤 `v3_문자주문`에서 `select('id,내용,삭제됨').in('id', R들)`(`제때` 10초)로 **서버에서 되읽어** 같은 대조 + `삭제됨` 아님. 못 맞으면 1초 쉬고 두 번 더. 그래도 안 되면 **지우지 않고** `{오류:'예약에 담긴 것을 서버에서 확인하지 못해 주문은 그대로 두었습니다. 다시 누르면 이어서 합니다'}`. 서버가 꺼진(로컬 시험) 때는 ⓐ만.
   > 🔴 로컬 되읽기만으로는 모자란다 — `01 저장()`은 localStorage 쓰기가 실패해도 캐시에 남겨 `읽기()`가 성공한 것처럼 보인다. 큐는 표마다 따로 upsert 되므로(01c 73행) 주문 삭제만 먼저 서버에 닿을 수 있다.
6. **지운다** — `지금줄들.forEach(o => 저.지우기(주문, o.id); ZG.서비스품목.출고지우기(o.id))`(08c 건삭제와 같은 두 줄).
7. **맨 끝에** 흡수한 문자주문을 `저.지우기(문자주문, r.id)` — 그 일을 R 이 이어받았다. 남겨 두면 같은 날 목록에 「주문올림」 빈 껍데기와 R 이 둘 다 뜬다. 여기서 끊기면 껍데기만 남는다(17단계 §5 「주문탭에서 먼저 지운 문자주문」과 같은 상태 — 올림 삭제로 지울 수 있다).

### 4-5 되살리기 — `20e 되살리기(id)` → `{번호}` | `{오류}`
`20a 주문올리기` 첫머리에서 `r.원본줄들`이면 `되살리기(id)`로 넘긴다(받는 분 판을 안 연다 — 줄에 다 있다). 20c 의 `주문올리기` 단추도 원본 줄은 판을 열지 않고 바로 부른다.
1. `예약중(r)` · 원본줄들 있음 · `올릴수있나(r)` 아니면 오류.
2. `주문들 = 읽기(주문)` · `이미 = 원본 중 id 가 주문들에 있는 줄`(끊긴 뒤 재시도).
3. **주문번호** — `원번호 = 원본 줄의 주문번호(빈 값 아닌 첫 것)`
   - `이미`가 있으면 **그 줄의 번호를 따른다**(재시도 때 번호가 갈라지지 않게).
   - 아니고 `원번호`가 **원본 아닌 다른 줄**에 쓰이고 있으면(충돌) → **새 번호** `20a 새주문번호(오늘, 주문들)`.
   - 아니면 `원번호` 그대로. 수동주문은 원래 번호가 비어 있어 비운 채 둔다.
   > **새 번호로 정한 근거** — 거부하면 그 예약은 영영 못 올린다(번호는 남이 지우기 전엔 안 비고, 우람님이 손댈 길이 없다). 충돌은 실제로 난다: 오늘 올린 문자주문(261013-03)을 같은 날 예약으로 옮기면 `새주문번호()`가 남은 줄만 보고 다음 문자주문에 03 을 다시 준다(17단계④와 같은 뿌리).
4. 원본 중 `이미`에 없는 줄마다 복사본에 — `주문번호=번호` · `주문일=오늘`(옛 날짜면 주문 조회 「오늘」에 안 떠 그날 안 보내신다) · `출력번호` **지움**(옛 날 출력번호가 남으면 08i 가 다시 안 매겨 그날 번호·동봉카드와 겹친다) · `문자주문id = r.id` → `덧붙이기`. `서비스===true` 줄은 이어서 `ZG.서비스품목.출고맞추기(줄)`(옮길 때 지운 서비스 출고를 다시 만든다).
5. **맨 끝에** `바꾸기(r.id, {상태:'올림', 올린주문번호: 번호, 올린일시, 원본줄들: null, 수정일시})`. 여기 전에 끊기면 r 은 예약 그대로 — 다시 누르면 2단계가 남은 줄만 더한다.

**`문자주문id = r.id`를 모든 되살린 줄에(서비스 줄 포함) 붙이는 이유** — 17단계④ 가드 `번호살아있나(r, 제줄)`는 **r.id 를 단 줄**에 그 번호가 있을 때만 번호로 잡는다. 붙여야 ⓐ 발송완료·송장이 이 r 에 잡히고 ⓑ `지울줄(r)`이 서비스 줄까지 잡아 올림 삭제가 고아를 안 남기며 ⓒ 번호를 새로 받았어도 옛 번호를 쓰는 남의 주문을 안 집는다. 수동주문(번호 빈칸)은 번호로는 아무것도 못 잡으므로 id 가 유일한 끈이다. `대상줄()`은 서비스 줄을 빼므로 발송 품목은 그대로다.

### 4-6 옮긴 줄(원본 있음)의 펼친 판 — `20f 원본판(r, 폰)`
되살림은 `원본줄들`을 쓴다 — 사본에서 품목·사람을 고치면 **조용히 버려진다.** 그래서 원본 줄은 **예약칸만 고칠 수 있다.** 받는 분·전화·주소·품목(유통명 규격 수량 단가)은 읽기 글로 보이고, 끝줄은 `삭제 · 💬 문자 · 주문올리기 · 저장`. `20a 고치기`도 원본 줄이면 `예약`·`예약일`만 받는다(데이터층이 한 번 더 막는다).
지우기 확인 본문에 한 줄 더: `주문탭에서 옮겨 온 주문입니다 — 지우면 주문도 함께 없어집니다`(위험).
접힌 줄은 상태칩 자리에 `.옴` `↩ 주문탭에서 옴`(시안 ②·③ⓒ).

## 6. 가정 (확인 전, 이대로 만든다)

1. §0 — 예약 줄도 오늘 갈래에 칩을 단 채 보인다(시안대로).
2. 「오늘 n」 칩의 n 은 **고른 날** 건수(헤더와 같다). 다른 날을 고르면 칩 글은 「오늘」 그대로.
3. 로젠 파일을 이미 뽑은(출력번호 있는) 수동 건도 넘길 수 있다.
4. 옮긴 줄은 품목·사람을 못 고친다 — 올린 뒤 주문탭 수정으로 고친다.
5. PC 예약 갈래의 달력은 예약일 점을 보이고, 날을 누르면 그 날의 오늘 갈래로 간다.
6. 여러 건을 넘기면 건마다 예약 줄 하나, 예약일은 모두 같다.
