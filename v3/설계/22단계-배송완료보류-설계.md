# 22단계 — 배송완료 보류 설계 (22c 확정 기준 · 10/15 갱신)

시안 `시안/22c-배송완료보류-팝업-macA.html`(+PC·폰 PNG) 컨펌. **22·22b는 폐기.** 새 Supabase 표·SQL 없음. 공통 규약은 「1단계 설계 §10 그대로」.
🔴 **보류 단위 = 묶음(같은 사람·같은 송장)** — 카드 한 장 = 묶음 하나. 새 화면 없음: 주문 조회 그대로 + 🚚 팝업 + 「배송보류」 탭.

## 1. 그대로 두는 것 (작업 사본에 이미 있음 — 살린다)

- 주문줄 칸 `보류`(true/false) · `보류송장` · `보류일`('YYYY-MM-DD'). 쓰기는 `저.바꾸기(주문, id, …)` 줄 하나 = 행 하나. 해제는 `{보류:false}`만(송장·날은 남김). 서비스 줄·출고 있는 줄엔 안 단다.
- 관문 — `08f.넘길줄만` 사유 `'보류'` 한 줄 · `08g.판정하기` 판정 `'보류'`(묶음 통째, 출고 안 만듦). `08f.송장표`·`08l.보낼판정`에 `'보류'`가 없어 송장 파일·카페24에 저절로 안 섞인다.
- `08u` — `보류인가·걸기·풀기·건들·미리셈·대상` 그대로. 열쇠 = `묶음키|보류송장`, 보류일 오래된 것부터.
- `08g` — 출고는 **지금처럼 파일 처리 순간**(`처리()→판정하기`) 생긴다. 보류는 **누르는 그 순간** 저장(`보류로`=출고되돌리기+`08u.걸기` · `완료로`=`풀기→넘길줄만→출고넣기(같은 배치)`). [저장] = 카페24 체크 켜짐이면 `08m.열기({…, 그다음:닫기})`, 꺼짐이면 닫기. 이유는 앞 판과 같다(되돌리기·이름찾기가 「이미 만든 출고」 위에 서 있다 · ✕로 닫아도 송장을 안 잃는다).

## 2. 🚚 배송완료 팝업 — `08g` 결과창을 카드로 (PC 모달 800px · 폰 아래 시트)

- **창 하나로 합친다.** 🚚 → 바로 팝업. 머리 `🚚 배송완료 N건`(N=카드 수) + ✕. 도구줄 = 검색칸 `품목명 · 고객명` + `[📄 로젠 엑셀 불러오기]`(+PC만 작게 `[⬇ 송장 파일]` = 기존 `내려받기`).
  - 파일 전: 몸 = 지금 `고르기창` 내용(PC 끌어놓기 칸 · `손처리줄`). 검색칸 꺼짐. 파일 고르면 곧바로 `처리()`(「배송완료 처리」 단추 없앤다).
  - 결과 있는데 다시 불러오기 = `닫기()→열기()→파일찾기()`(앞 파일의 출고·보류는 이미 저장됨 — 지금 「닫고 다시 돌리기」와 같다).
- **카드** = `묶음들()`(운송장번호로 묶음) 중 `주문줄들`이 있는 것. 🔴 `처리()` 때 `것.묶키 = 묶음열쇠(것)`로 **고정**하고 묶음들()은 `묶키`로 묶는다(송장을 고치면 열쇠가 바뀌므로).
  머리: 네모칸(`.cb.big`) · 수하인 · 마켓(`.mall`) · `M/D 주문` / 줄: 품목코드 · 유통명 · 규격 · `×수량`(서비스 줄 뺌) / 아래: `송장` + 입력칸.
  - 체크 켬 = 판정 정상·처리 · 끔 = 보류(`.oc.off` 회색 점선 + `.hold 송장만 저장`). **끄기 = `보류로` · 켜기 = `완료로`**(앞 판 함수 그대로).
  - 판정 이미·미차감·운송장번호 없음 → 네모칸 못 누름 + 배지(`.res dup 이미 나감` / `.res chk 품목코드 없음`).
  - 송장칸 고침(blur·Enter, 빈칸이면 흔들고 되돌림) → `송장고치기(묶, 새)`: 묶음 안 `것.운송장번호=새` · 체크 켬이면 `출고되돌리기→출고넣기(같은 배치, 새 송장)` · 보류면 `08u.걸기(줄들, 새, 그 보류일)`. 08f는 안 고친다.
  - 검색 = 수하인·유통명·원본코드·품목코드 포함이면 보임(`hidden`만 바꾼다, 다시 그리지 않는다).
- 카드 아래 `.done` 줄(완료글·전부되돌리기)·`확인상자()`(이름으로 찾기)는 **그대로** 둔다 — 시안에 안 그렸을 뿐 되돌리기·이름찾기 길이다.
- **발 줄**(시안 `.savebar` / 폰 `.selfix`): `배송완료 N건 · 재고 −N주` | `⏸ 보류 N건 · 송장만 저장`(N = **카드 수**, 앞 판 줄 수에서 바꾼다) | 체크 `카페24 송장 올리기`(기본 켬, 대상 0이면 숨김, 서버 없음이면 꺼짐) | `[저장]`. `[닫기]` 단추는 없앤다(✕가 있다).
- **폰 [저장]** — 08m은 PC 창이라 안 띄운다: 카페24 켬이면 `u.확인`(`카페24에 송장 N건을 올릴까요`) → `08u.카페24올리기(짝들)` → 토스트 → 닫기. 심폴짝은 폰에서 안 보낸다(「심폴 N건은 PC에서」 한 줄).
- 작업 사본의 **`.cnts` 넷 · 송장 표(`송장표그리기`·`묶음행`·`.dsel`) · `결과배지` · `넓게` 옵션 · `.rsum`은 지운다.** `보류로`·`완료로`·`보류줄수`(→건수로)·`출고셈.주`·`발새로`·`저장`·`대상`·`c24켬`·판정하기 보류 분기·`줄만들기` 보류 칸은 살린다.

## 3. `08u-배송보류.js` — 고칠 것 둘

- `보내기(건들, {카페24})` — 🔴 **심폴은 보내지 않는다**(손님에게 문자가 나간다). 심폴짝 수는 `결.심폴빠짐`으로만 돌려준다.
- 카페24 보내는 덩어리(08l.보내기(…,true) → 됨·이미로 `상태되쓰기`, 실패는 `실패[]`)를 `카페24올리기(짝들) → Promise<{됨, 실패}>`로 떼어 내보낸다 — `보내기`와 08g 폰 저장이 같이 쓴다.

## 4. `08b-주문목록.js` — 상태칩 → 상단 탭

- `상태칩목록()`은 살린다. PC 칩판의 「배송」 칩 묶음(1042행 부근)·폰 `상태칩줄`(624행 부근)을 **시안 `.stabs`**로 바꾼다: `전체 · 배송준비중 N · 배송완료 · 배송보류 [N]`. PC는 서브탭 아래·칩판 위 한 줄, 폰은 찾기칸 아래. 배송준비중 N = 그 탭의 건 수(마켓·찾기 무시) · 배송보류 N = `08u.건들().length`, `.hn` 회색 알약(0이면 숫자 없음). `⚠ 기간 무시` 글은 준비중일 때 칩판에 그대로.
- 🔴 **배송준비중 탭에서 보류 묶음을 뺀다**(148행 필터) — 탭이 서로 겹치면 보류 건이 출고리스트에 또 찍힌다. 열쇠 `(묶음키)|주문일`로 보류 줄과 같은 묶음의 서비스 줄도 뺀다. 전체 탭 배지는 보류 줄이 섞인 건이면 `배송보류`(회색 `.hold`). `준비중인가`·`나갔나` 함수는 안 고친다.
- 배송보류 탭: `보류줄들()`·`기간무시`·`기간글` 살림. PC는 칩판의 **기간 칸·기간칩을 숨긴다**(찾기·마켓은 그대로), 폰은 `날바.hidden=true`(작업 사본의 「보류 · 전체 기간」 글은 지운다). 채우기에서 `ZG.보류목록.PC/폰(…)`으로 가르는 두 줄 살림.
- 🔴 **폰 상세 `손처리칸`(송장+dsel+✋저장) 은 HEAD로 되돌린다** — 22c엔 없다. 보류 건 상세는 ✋ 단추 없이(관문이 막는다) 둔다.
- 폰 `topbtns`에 `🚚 배송완료` 추가(시안 ①) → `ZG.주문파일.배송완료()`.
- 🔴 작업 사본 08b의 **주문수집 부분(`카페24받기`/`주문수집하기` 순서 바뀐 덩어리)은 22단계 것이 아니다** — 다른 창 미커밋분. 건드리지 말고, 커밋은 `git add -p`로 22 덩어리만.

## 5. `08v-보류목록.js` — 다시 쓴다 (~170줄)

`ZG.보류목록 = { 묶음카드(건, 옵션), PC(카드, 줄들, 다시), 폰(목록, 줄들, 다시), 넘기기(건, 끝) }`
**지운다**: `고른`·`고른것들`·`보내기단추`·`.selbar`·`.selfix`·`.hcard`·`보내기물음`(직접 그린 askbox·체크칸). **살린다**: `나이글`·`품목줄`·`결과알림`.
- `묶음카드` — 08g 팝업과 보류 탭이 같이 쓰는 카드 한 장(시안 `.oc`). 옵션: `체크`(켬/끔/없음)·`송장`(입력/글+✎)·`머리배지`·`아래단추`·`꺼짐`.
- 🔴 **PC — 한 카드**(22c 시안 ②의 좌우 갈린 표 아님): 머리 `받는분 · 전화` · 주문한 곳(`.mall`) · `.hold 배송보류` `M/D · N일`(`.age`, 3일 이상 `.old` 빨강) / 줄마다 `품목코드 · 품목 · 규격 · ×수량 · 금액` / 아래 `송장 31245678811 [✎]` + 오른쪽 `[✋ 배송완료로 넘기기]`. 카드 위 `h3 배송보류 N건`, 카드들은 `.ogrid` 2열.
- **폰** — 22c ③ 그대로: 이름·`.hold`·날·마켓 / 유통명 규격 N주 / 송장 + ✎ / 폭 꽉 찬 `[✋ 배송완료로 넘기기]`. 카드 눌러 상세로 가지 않는다(› 없음).
- **✎** → 그 자리 입력칸 + `[저장]`(Enter 저장 · Esc 취소 · 빈칸 흔들기) → `08u.걸기(건.줄들, 새, 건.보류일)` → `다시()`.
- **넘기기** = 08n 동작 + 카페24: `u.확인({제목:'N건을 배송완료로 넘길까요', 본문: '재고 −N주 · 카페24 송장 올림' + 수하인·품목·송장 줄, 확인글:'넘기기'})`(N=상품 줄 수, 수는 `08u.미리셈`) → `08u.보내기([건], {카페24: 대상>0 && 서버})` → 토스트 `✓ {수하인} N건 배송완료 · 재고 −N주 · 카페24 송장 올림` → 실패·심폴빠짐 있으면 `결과알림` → `ZG.주문.다시그리기()`. 일괄선택·보내기 바 없음.
